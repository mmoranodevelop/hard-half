# Social Carousel

**LinkedIn / IG 4:5 carousel pack** — slides + caption. One swipeable argument: hook, stakes, reframe, payload, synthesis, one ask. Default canvas 1080×1350 (4:5). Glass / grain. Lockup from the user. Not a board memo.

Method origin: platform help (LinkedIn document post, IG image carousel) + the default visual kit. Ranking folklore stays out.

If they want a virality lecture: one paragraph then produce or stop.

## When to use

- "Make a carousel for LinkedIn / Instagram"
- Turn a thesis / thread / newsletter into 4:5 slides
- Critique or redesign a pasted deck
- (Optional, under produce) define a kit other than the default

## When not to use

- Reels, Stories, Shorts, talking-head — not this skill
- Covering email / board paper — [Executive Board Memo](../../management/executive-board-memo/SKILL.md)
- Long argument essay — [Thought Leadership Thesis](../../branding/thought-leadership-thesis/SKILL.md)
- Cadence of posts, not this pack — [Editorial Calendar](../../branding/editorial-calendar/SKILL.md)
- Voice overlay only — [Voice Blueprint](../../writing/voice-blueprint/SKILL.md)
- Bio / one-pager identity sheet — [Bio Pack](../../branding/bio-pack/SKILL.md)
- Paid carousel ads — route away (different product)
- A single punchline — make **one image** or a text post, not this pack

## Modes

| Mode | When | Output |
|---|---|---|
| **produce** | Default. New carousel from a thesis | Pack (slides + caption). Sub-mode **kit**: 1-page visual kit if they want a system other than the default. Sub-mode **adapt**: same thesis, native rewrite for another surface |
| **redline** | They pasted a deck or copy | Force contestable thesis, one idea per slide, default chrome; kill padding and "Swipe" |
| **refuse** | No contestable thesis after one ask | Issues list. Stop. Offer a single image or a text post |

If unclear: **produce**. Kit is never a substitute for refuse.

## Hard rules

1. **No thesis, no carousel.** A thesis is a complete sentence a sceptic could disagree with. "5 tips for personal branding" is a topic. Refuse topics.
2. **Personal brand = this person.** Lived proof (a number they earned, a mistake, a method they use). If you delete the name and any creator could post it, it is sludge.
3. **One idea per slide.** Headline + short body. Slide 1 is an ad for the rest. No "Swipe".
4. **Every slide has a job.** Padding to hit a count is a defect. Default argument: 8 slides (floor 6, ceiling 12 unless every extra still has a job).
5. **Native packaging.** LinkedIn organic argument = **PDF document post**, pages 1080×1350 (4:5). Instagram = same-ratio images; first slide is the grid cover. Do not dump a LinkedIn PDF onto X.
6. **Caption is a second door, not a transcript.** One CTA verb.
7. **Default kit (locked):** ink `#111318`, cream `#F5F3EE`, accent `#FF4F32`, Instrument Sans + **one** Instrument Serif italic keyword in accent, lockup from the **user's initials + name** top-left every slide, dark grain, glass cards. Face photos **user-supplied**, never generated. Never leave `YOUR NAME` / `XX` on a shipped slide.
8. **Virality is an outcome.** Do not claim a formula or an algorithm hack. Cite only published ranking signals; do not write ranking folklore into the deck.
9. **Do not steal.** Original objects on a stolen silhouette still fail.
10. **Do not invent numbers.** Holes stay holes.

## Intake

If **two** of 1–4 are missing after one round: issues list, not a fake pack.

1. Platform (primary). Others are produce/adapt — load-bearing
2. Audience (role + situation) — load-bearing
3. Thesis — one complete sentence they would defend — load-bearing
4. Proof — lived; "studies show" is not proof unless they cite a source they have read — load-bearing
5. CTA — one verb and the destination
6. Voice — if a [Voice Blueprint](../../writing/voice-blueprint/SKILL.md) instance exists, load **one** overlay. Do not invent a persona
7. Visual kit — load the default (`assets/visual-kit.yaml`). Fill `lockup_name` and `monogram` from the user. Kit sub-mode only if they want a different system.

## QA (must pass)

1. Thesis is a disagreeable complete sentence.
2. Slide 1 readable in two seconds.
3. No padding (delete-test).
4. One idea per slide; body short.
5. Proof is lived and specific (or hole).
6. Caption is a door, not a transcript.
7. One CTA verb.
8. Default chrome: lockup (user name), grain, glass, one Serif keyword; no sludge (wrong type family, ASK Rail, "Swipe", generated likeness, leftover placeholders).
9. Packaging is native 4:5 for the primary platform.
10. Not a board memo.

If 1, 3, or 5 fail: do not ship.

## Escalate / stop

- No contestable thesis after one ask → refuse.
- Clone of a named creator's carousel → refuse the silhouette, not just the objects.
- Engagement-bait ("comment YES", pods) → refuse.
- Generated face → refuse; ask for a photo.
- Legal / medical / financial claims without a source → hole or hedge; do not invent numbers.
- Ads → route away.
