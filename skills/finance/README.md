# finance

Cash, close, capital, and the numbers a principal cannot invent.

## Model-invoked

Reachable by you *or* selected automatically by the agent when a task matches.

- [`cap-table`](cap-table/SKILL.md) — Use when the MD needs who owns what fully diluted, pre/post this round or SAFE stack, option-pool top-up, and who is diluted — a business page, not a term-sheet rewrite.
- [`close-calendar`](close-calendar/SKILL.md) — Use when month-end needs named owners, business-day slots, and a lock date — not “finance will close.” NOT for synergy-tracker (first combined close), not operating-review (exec exception pack), not day1-continuity (M&A morning).
- [`covenant-compliance`](covenant-compliance/SKILL.md) — Use when flashing lender covenant status: headroom, breach path, cure options, one ASK.
- [`data-reconciliation`](data-reconciliation/SKILL.md) — Use when matching and reconciling records across 2+ systems / CSV / Excel — billing hours vs tickets, CRM vs ERP, timesheet vs PSA, payroll vs HRIS, AP 3-way, intercompany.
- [`decision-debt`](decision-debt/SKILL.md) — Use when aged undecided items need a single owner, age in days, and a next decision date.
- [`follow-on`](follow-on/SKILL.md) — Use when the question is yes / partial / no on this insider, pro-rata, or extra check — with reserve and signal.
- [`insurance-renewal`](insurance-renewal/SKILL.md) — Use when renewing D&O / cyber / E&O: coverage vs risk appetite, gaps, premium vs limit ASK.
- [`pe-monthly-flash`](pe-monthly-flash/SKILL.md) — Use when sending the PE/sponsor monthly flash: KPI strip + cash + 3 risks + 1 ask.
- [`reforecast`](reforecast/SKILL.md) — Use when the remaining fiscal year must be rewritten vs the original plan (actuals occupy closed months; open months are re-assumed).
- [`working-capital`](working-capital/SKILL.md) — Use when this month’s operating cycle is the object: DSO, DIO, DPO, CCC, and one cash ASK.
