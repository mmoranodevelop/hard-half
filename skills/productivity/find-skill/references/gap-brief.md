# Gap brief

A missing skill is a hypothesis. Most hypotheses should die here.

## Verdicts

| Verdict | When it is honest |
|---|---|
| **Deserves a skill** | The same multi-step process will be asked again, across repos, and the default agent gets it wrong in a nameable way |
| **Belongs in CLAUDE.md** | It is a fact about *this* repo (stack, paths, house style) |
| **Just ask once** | A one-off, however elaborate |
| **Already exists** | You missed it on the index — go back to Find. Name the skill you missed |

## What the brief must contain

- **Job** as a process in order, not a topic ("turn a raw client email into a tracker ticket bound to live fields", not "project management")
- **Why the default fails** in one sentence you could test
- **Nearest two existing skills** and the artifact they produce instead
- **Anti-triggers** — the jobs this new skill must refuse
- **Leading word** or an explicit none

If you cannot write the anti-triggers, the skill is not scoped. Verdict = just ask, or go back to the index.

## Hand-off

`create-skill` writes the file. This skill writes the brief. Chaining them without a yes from the user is how the catalog grows sludge.
