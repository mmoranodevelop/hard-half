# productivity

Personal and team operating systems — the work around the work.

## Model-invoked

Reachable by you *or* selected automatically by the agent when a task matches.

- [`find-skill`](find-skill/SKILL.md) — Find, browse, or recommend the skill that owns a job; if none fits, write a gap brief.
- [`commitment-register`](commitment-register/SKILL.md) — Use when tracking promises an MD made to board, customers, or the team, with owners and dates — an integrity register.
- [`create-project`](create-project/SKILL.md) — Scaffold a brand-new development project: the folder, an architecture that fits what is actually being built, and the agent-facing files that let a fresh session pick the work up cold.
- [`create-skill`](create-skill/SKILL.md) — Build a new agent skill, or repair one that isn't working.
- [`signal-vs-noise`](signal-vs-noise/SKILL.md) — Cut everything competing for your attention down to the 3–5 things that actually move the mission in the next 18 hours, and give every remaining item a disposition — delegated, deferred, batched, or deleted.
- [`calendar-audit`](calendar-audit/SKILL.md) — Use when auditing a calendar to kill, delegate, or keep meetings and to protect deep-work blocks.
- [`weekly-cadence`](weekly-cadence/SKILL.md) — Use when designing or resetting an MD's personal week: contribution block, process meetings, Friday close.
- [`wip-limit`](wip-limit/SKILL.md) — Use when too much is in flight: personal or program work-in-progress.

## User-invoked

Reachable only by typing the name. Their job is to orchestrate.

- [`repo-setup`](repo-setup/SKILL.md) — One-time per repo: where generated pages go, which categories matter, default audience.

The conceptual vocabulary in `create-skill` — leading words, the information hierarchy, the no-op test, sediment, sprawl, prompting the positive — is adapted from [`writing-great-skills`](https://github.com/mattpocock/skills) by Matt Pocock (MIT).
