# delivery

Service delivery operations — capacity, SLA, launch, leakage.

## Model-invoked

Reachable by you *or* selected automatically by the agent when a task matches.

- [`capacity-demand`](capacity-demand/SKILL.md) — Use when PS/delivery needs a 13-week sold-demand vs capacity view and a hire/sub decision.
- [`deprecation-notice`](deprecation-notice/SKILL.md) — Use when a BAU feature or SKU needs last-sell, last-support, and grandfather on one customer notice.
- [`e2e-manual-test-list`](e2e-manual-test-list/SKILL.md) — Use when designing a MANUAL end-to-end test inventory for an app, web app, or enterprise system from PRD / stories / AC / Figma — prioritized list humans (or later automation) execute.
- [`launch-brief`](launch-brief/SKILL.md) — Use when a customer-facing go/no-go needs the promise, the support path, and the kill-old-path.
- [`rate-card`](rate-card/SKILL.md) — Use when the team needs the frozen list they may quote until a dated review.
- [`resource-collision`](resource-collision/SKILL.md) — Use when the same scarce people or skills are contended across ≥2 projects this horizon: collision table, priority rule, resolve ASK.
- [`severity-customer`](severity-customer/SKILL.md) — Use after the first 60–90 minutes of a customer-visible incident for owner, customer sentence, and next-update clock.
- [`sla-credit`](sla-credit/SKILL.md) — Use after an SLA breach: credit owed, root cause class, customer letter spine, prevent-repeat ASK.
- [`staffing-mix`](staffing-mix/SKILL.md) — Use when one named program needs an onshore / contractor / vendor split that still clears the SOW margin.
- [`unbilled-leakage`](unbilled-leakage/SKILL.md) — Use when hours or scope were eaten without a change request and the invoice line is missing.
- [`utilization-bench`](utilization-bench/SKILL.md) — Use when named people are off billable this week and need a date back on work plus an owner of the next seat.
