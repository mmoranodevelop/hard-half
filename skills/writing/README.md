# writing

Voice, tone, and documents as prose.

## Model-invoked

Reachable by you *or* selected automatically by the agent when a task matches.

- [`all-hands`](all-hands/SKILL.md) — Use when writing the company or program all-hands narrative after a decision: what we decided, why, what it means, what we will not do, Q&A, manager cascade.
- [`board-qa-prep`](board-qa-prep/SKILL.md) — Use when prepping hostile or real board questions plus 30-second answers before a board or IC sitting.
- [`crisis-holding`](crisis-holding/SKILL.md) — Use in the first 60–90 minutes of a live issue: holding statement (known, unknown, doing, next-update clock) plus who must know.
- [`difficult-conversation`](difficult-conversation/SKILL.md) — Use when preparing a hard conversation (performance, conflict, a no): purpose, facts vs story, 30–60s opening, one ask, fallback.
- [`investor-update`](investor-update/SKILL.md) — Use for a monthly letter to investors: miss first, same metrics, cash/burn/ runway, specific asks.
- [`meeting-notes-to-decisions`](meeting-notes-to-decisions/SKILL.md) — Use after a meeting to turn notes into a sendable decision log: decided, pending, parked, each with owner and date.
- [`offer-conversation`](offer-conversation/SKILL.md) — Use when closing or walking a named offer: comp, scope, start date, fallback.
- [`principal-brief`](principal-brief/SKILL.md) — Use when a staffer must brief a principal on one page: question, recommendation, three facts, ask.
- [`pyramid-principle`](pyramid-principle/SKILL.md) — Use when writing or rewriting an email, Slack/chat message, verbal update, or argumentative deck with Barbara Minto's pyramid: answer first, grouped key lines, MECE, SCQ opening.
- [`voice-blueprint`](voice-blueprint/SKILL.md) — Map a person's real writing voice into versioned blueprints other agents can load when writing email, messages, or documents.
