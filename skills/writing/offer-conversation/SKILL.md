# Offer Conversation

**Offer conversation pack** — close or walk a named candidate: total comp, scope, start date, walk-away, fallback. Default: venture MD/hiring manager; same spine for F500 with HR in the room.

Method origin: Google re:Work public — call first, then the letter. Harvard PON public: know your BATNA / walk-away before you speak. The hiring scorecard still binds.

If they want a lecture on how to negotiate: one paragraph then produce or stop. Do not impersonate counsel on the contract.

## When to use

- You are making the offer call (or walking it) this week
- Comp, title, scope, or start date is the live issue
- Counter-offer from the current employer is on the table
- You must decline a candidate you liked, or they will decline you

## When not to use

- Opening the role, loop, debrief — [Hiring Scorecard](../../management/hiring-scorecard/SKILL.md)
- A hard conversation that is not an offer — [Difficult Conversation](../../writing/difficult-conversation/SKILL.md)
- First 90 days after they sign — [Ninety-Day Onboarding](../../learning/ninety-day-onboarding/SKILL.md)
- The box they enter — [Org One-Pager](../../management/org-one-pager/SKILL.md)
- The employment contract / equity docs — counsel / HR own the paper
- Candidate-side "how do I extract more from the offer" coaching as the job — refuse

## Modes

| Mode | When | Output |
|---|---|---|
| **produce** | Default. Named candidate, offer exists or should | Close script **or** walk script + fallback |
| **redline** | They pasted a call plan or an email offer | Force call-then-letter; add walk-away and scope |
| **refuse** | No scorecard, no numbers, and they want you to "make them excited" | Issues list. Stop |

Skin: **close** | **walk**. If they might still take it, close. If you will not move, walk.

## Hard rules

1. **Call, then letter.** Verbal first, written follows. Do not email a number cold. Do not accept a verbal "yes" as the file.
2. **Walk-away is written before the call.** Comp floor, scope floor, latest start date.
3. **Scope is the scorecard, not a vibe.** Mission + 12-month outcomes. Title inflation without outcome change is a fail unless you mean it and HR can pay it.
4. **Total comp, in parts, paused.** Base, bonus, equity (units, vest, what a unit is worth **as a labelled assumption**), sign-on, benefits that actually move the decision. Do not quote a made-up 409A.
5. **Start date is a date**, with the fallback (earliest / latest you will tolerate).
6. **Close path:** they accept / they ask for time (cap it) / they counter (map to walk-away) / they walk (leave the door if true).
7. **Walk path:** thank, one true sentence why, do not argue them into a role they will fail.
8. **Illegal is a stop.** Do not trade on protected characteristics, visa threats, or similar. HR/counsel. This skill does not write that.

## Intake

If **candidate** and **the number you will actually pay** are both missing after one round: issues list.

1. Candidate, role, scorecard pointer (or "none" → hole)
2. Skin: close or walk
3. Comp you can offer (parts) and the walk-away
4. Scope / title / manager / start date you can live with
5. Known other offer / current-employer counter
6. Who is on the call (recruiter / HM / HR)
7. Venture or F500 (venture default)

## Output shape

```
OFFER CONVERSATION  |  [candidate]  |  [role]  |  [date]
Skin: close | walk     Scorecard: [pointer or HOLE]
Call then letter: yes    Written owner: [HR / you]

WALK-AWAY (before you dial)
Comp floor (total, parts): [ ]
Scope floor: [ ]
Start no later than: [ ]
If they need more than this: we walk / we escalate to [ ]

THE NUMBER (say in parts; pause)
Base: [ ]  Bonus: [ ]  Equity: [units + vest + labelled value assumption]
Sign-on: [ ]  Other that moves this: [ ]
Scope (12-month outcomes): [ ]
Manager: [ ]  Start: [ ]  Flexibility: [ ]

SCRIPT (close)
Open (30s): the yes, the role in one sentence, then the parts
If they need time: back by [clock]
If they counter: map to walk-away; give-get (start, sign-on, scope) not silent yes
If they walk: thank, door, referral ask

SCRIPT (walk)
One true sentence. What happens to the role. Door if true. Stop.

FALLBACK IF THEY SAY NO
Keep / re-open search / second candidate: [ ]
Offer expiry: [ ]

DO NOT SAY
- [a number you cannot pay, a title HR will not paper, a 409A you invented]

HOLES
- [ ]
```

## QA (must pass)

1. Named candidate and role.
2. Walk-away written before the script.
3. Comp in parts; equity value labelled as assumption or hole.
4. Scope = scorecard outcomes, not a slogan.
5. Start date present.
6. Call-then-letter, written owner named.
7. Fallback if they say no.
8. Not a hiring scorecard rewrite.
9. No illegal criteria.
10. One page.

If 2, 3, or 9 fail: do not ship.

## Escalate / stop

- No scorecard → you may still close only if they accept the hole and the outcomes are written now; else [Hiring Scorecard](../../management/hiring-scorecard/SKILL.md).
- They want you to beat a competing offer with no floor → refuse; write the walk-away first.
- Equity / visa / non-compete / garden leave — HR/counsel own the paper; this skill owns the talk.
- They want a PIP-toned walk with no evidence → refuse the vibe; one true sentence or stop.
- Candidate-side max-extract coaching as the assignment → refuse; this is the employer's close/walk.
