# Cascade Script

**MANAGER CASCADE SCRIPT — may-say / must-escalate.** One to two pages, sendable to people-managers *before* their teams hear the news (or same day after the room). Default: venture. Same spine for F500 program. Write as if it will be screenshotted (Pichai TGIF: **~25%** watched vs **80%** a decade earlier; the room leaked).

Method origin: MangoApps Manager Cascade Talking Points (headline fact, one action, approved answers, named escalation; managers **must not rewrite core facts**) + Kotter public (one town hall is a declaration; managers retell) already owned by [All-Hands](../../writing/all-hands/SKILL.md). This skill is the **standalone** kit when there is no town hall, or after it.

If they want a cascade lecture: one paragraph then produce or stop.

## When to use

- A decision exists and managers must retell it this week
- There is no town hall, or the town hall is not the vehicle
- Managers are about to get “forward the deck”

## When not to use

- Company/program town hall pack (spine + Q&A + cascade as one artifact) — [All-Hands](../../writing/all-hands/SKILL.md)
- M&A Day 1 legal employee pack — [Day-1 Employee Pack](../../ma/day1-employee-pack/SKILL.md)
- Behaviour / ADKAR this week — [Change Adoption](../../management/change-adoption/SKILL.md)
- First 60–90 min of an incident — [Crisis Holding](../../writing/crisis-holding/SKILL.md)
- One message per *named* stakeholder this week — [Stakeholder Message Map](../../comms/stakeholder-message-map/SKILL.md)
- A policy, SOP, or legal notice — those documents; this is not a substitute

## Modes

| Mode | When | Output |
|---|---|---|
| **produce** | Default. Decision exists | May-say / must-escalate kit + one huddle ASK |
| **redline** | They forwarded the deck or a pep script | Restore headline, one action, approved Q, named escalation |
| **refuse** | No decision yet; managers rewriting core facts; “forward the deck” as the kit | Issues list. Stop |

## Hard rules

1. **Decision exists.** Do not cascade a draft.
2. **Managers before teams** unless regulation forces otherwise. Same-day, in hours not days.
3. **May-say:** headline, why, one action, approved answers — in their own voice. They **cannot** change facts, dates, eligibility, or legal characterisation.
4. **Must-escalate:** anything not on the card → named person / inbox. Allowed sentence: “I don’t know, I’ll take it and come back by [time].”
5. Write as if **screenshotted**. Candid rooms leak.
6. One action + deadline. A “sent” flag is not a cascade. Close the loop same day: who has not run the huddle.
7. Do not invent facts, dates, or eligibility. Holes stay holes.

## Intake

If **the locked decision (headline fact)** and **the one action + deadline** are both missing after one round: issues list, not a fake kit.

1. Decision in one plain sentence (load-bearing). Status: decided, not draft
2. Why, in two sentences
3. What it means for “your team”
4. The **one action** + deadline (load-bearing with 1)
5. What is **fixed** vs what managers may localise
6. Likely questions; named escalation person / inbox
7. Who must run the huddle by when; who is already informed

## Output shape

```
MANAGER CASCADE  |  [decision, one line]  |  date: [today]
For: people-managers     Before teams: Y/N     Screenshot-safe: yes

HEADLINE FACT (sentence one — do not rewrite)
[plain language they can repeat]

WHY (two sentences)
[ ]

YOUR TEAM
[what changes Monday]

ONE ACTION  |  deadline: [date/time tz]
[exactly one]     Owner of huddle: [manager]     Close-the-loop owner: [ ]

FIXED (do not change)     LOCALISE (voice / examples only)
[facts, dates, eligibility, legal]     [how you say it to your team]

APPROVED Q&A (5–8)
Q: [ ]   A: [verbatim]

MUST-ESCALATE → [named person / inbox]
Legal / HR / named exception / anything not on this card.
Allowed: “I don’t know. I’ll come back by [time].”
DO NOT SPECULATE: [ ]

8-MIN HUDDLE (optional)
0:00 headline  1:00 why  3:00 action  5:00 Q from card  7:00 escalate line

ASK: every named manager runs the huddle by [time tz]. Owner: [ ]. Date: [ ].
HOLES: [ ]
```

## QA (must pass)

1. Headline fact in sentence one, not rewriteable.
2. Exactly one action + deadline.
3. Named escalation person/inbox.
4. One ASK + owner + date (huddle close-the-loop).
5. Not “forward the deck.” Not all-hands. Not Day-1 legal. Not ADKAR.
6. No invented facts, dates, or eligibility.

If 1, 2, 3, or 4 fail: do not ship.

## Escalate / stop

- No decision yet → refuse.
- Managers rewriting core facts → refuse; restore the lock.
- Forward-the-deck as the kit → refuse.
