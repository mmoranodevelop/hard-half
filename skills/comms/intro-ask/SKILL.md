# Intro Ask

**INTRO ASK — who asks whom for whom, double opt-in, forwardable.** One short email the connector can forward unchanged. Default: venture MD. Same spine for F500. Hoffman: only check if **>80%** probability of yes.

Method origin: Fred Wilson, *The Double Opt-In Introduction* (AVC, 3 Nov 2009) — ask each to opt in **before** the intro + Reid Hoffman (27 Jul 2026) — intro is a bet both sides get value; skip opt-in and you signal disrespect or power; want **100%** of completed intros to succeed + Auren Hoffman (14 Sep 2025) — Ask → Forward → Reply → Connect → Schedule; BCC the connector.

If they want an intro-etiquette lecture: one paragraph then produce or stop.

## When to use

- Named Asker → named Connector → named Target, this week
- The draft CCs both parties, DMs three intros, or promises an intro not yet cleared
- Need a forwardable paragraph the Target would actually want

## When not to use

- Customer reference, one sentence — [Reference Ask](../../commercial/reference-ask/SKILL.md)
- Partner construct — [Partner Memo](../../strategy/partner-memo/SKILL.md)
- Bio leave-behind — [Bio Pack](../../branding/bio-pack/SKILL.md)
- Letter *to* a customer CEO — [Customer CEO Letter](../../comms/customer-ceo-letter/SKILL.md)
- LinkedIn DM / WhatsApp / three intros in one note — refuse
- “Please intro me to [famous person]” with no value for the Target — refuse

## Modes

| Mode | When | Output |
|---|---|---|
| **produce** | Default. Three named humans; Target would want this | Forwardable email + double-opt-in line + ASK |
| **redline** | They CC’d both parties or promised the intro | Restore opt-in; one Target; value for Target |
| **refuse** | No Target value; promise without check; DM blast; <80% yes | Issues list. Stop |

## Hard rules

1. **Would the Target actually want this?** If not, abort. Do not spend the connector.
2. Only check if **>80%** yes (Reid Hoffman). Do not spray.
3. **One Target per email.** Named + title + firm + LinkedIn.
4. Explicit double opt-in: “Please check with [Target] first; totally fine if not.”
5. Body is a paragraph the Target would want to receive: why *they* benefit; proof you are real; the specific ask of a meeting.
6. You do not have the Target’s address yet. That is the point. Connector asks Target.
7. On yes: you reply in **hours**, not days. You schedule. **BCC the connector.** Do not keep them on the thread.
8. Never promise an intro you have not cleared. Never CC both parties without asking.
9. Close the loop privately with the connector: was it useful.
10. Do not invent Target facts. Holes stay holes.

## Intake

If **named Target + why they benefit** and **named Connector** are both missing after one round: issues list, not a fake email.

1. Asker (you): name, one-line proof you are real
2. Connector: named (load-bearing)
3. Target: named, title, firm, LinkedIn (load-bearing with 2)
4. Why the *Target* benefits — specific, not flattery
5. Specific ask of a meeting (15 min / intro to X)
6. Would Target want this? Yes-probability ≥80%? If no → stop
7. Date you will follow the connector if silent

## Output shape

```
INTRO ASK  |  Asker: [you]  →  Connector: [name]  →  Target: [name, title, firm]
Target LinkedIn: [ ]     Yes-probability: [≥80% / STOP]     Date: [this week]

SUBJECT: intro to [Target] — [specific reason]

Hi [Connector] —

One paragraph the Target would want (forward unchanged):
[why they benefit]. [proof I am real]. Ask: [15 min on X].

Please check with [Target] first (double opt-in). Totally fine if not.

Thank you,
[Asker]

OPTIONAL BLURB FOR THE FORWARD
[same paragraph, already in Target-facing voice]

ON YES
You reply in hours. Offer times. BCC [Connector] when scheduling.
Close the loop privately with [Connector]: was it useful.

ASK: send this to [Connector] by [date]. Owner: [Asker]. Date: [ ].
HOLES: [ ]
```

## QA (must pass)

1. Three named humans. One Target. LinkedIn present or labelled hole.
2. Value is for the Target, not the Asker. Yes-probability ≥80% or STOP.
3. Explicit double-opt-in sentence. Forwardable unchanged.
4. ASK + owner + date.
5. Not reference-ask, not bio-pack, not partner-memo. Not a CC of both parties.
6. No invented Target facts.

If 1, 2, 3, or 4 fail: do not ship.

## Escalate / stop

- CC both without asking → refuse.
- Promise an uncleared intro → refuse.
- Target would not want this / <80% yes → abort; do not spend the connector.
- Three intros in one note → refuse; split.
