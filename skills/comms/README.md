## Model-invoked

- [`champion-coach`](champion-coach/SKILL.md) — Use when the artifact is what OUR buyer-side Champion will say when we leave.

- [`investor-spoken`](investor-spoken/SKILL.md) — Use for a spoken slot on ALREADY PUBLIC facts, then Q&A.
- [`negotiation-trades`](negotiation-trades/SKILL.md) — Use when the artifact is a give/get table for this week’s commercial conversation, not a discount.
- [`objection-map`](objection-map/SKILL.md) — Use when named objections this week need a next line and an owner.
- [`pre-read`](pre-read/SKILL.md) — Use for the 2–5 page pack BEFORE the room: reader-complete, no voice-over.
- [`proof-story`](proof-story/SKILL.md) — Use when one customer, one metric, and permission status must travel into this week’s sales conversation.
- [`proposal-narrative`](proposal-narrative/SKILL.md) — Use when the cover the Economic Buyer will actually read is the object: answer first (APMP exec summary as compass).
- [`room-narrative`](room-narrative/SKILL.md) — Use for what you SAY in 8–12 minutes: interruptible spoken spine after the pre-read.
- [`stakeholder-message-map`](stakeholder-message-map/SKILL.md) — Use for this week’s one sentence per named person.
