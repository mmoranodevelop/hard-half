# Stakeholder Message Map

**THIS-WEEK MESSAGE MAP — one row per named person.** Locked “O” map of 3 facts/commitments/severity phrases that appear **verbatim** in every version. Default: venture MD/program. Same spine for F500. Covello: ideally **3** key messages, each **<9 words**.

Method origin: Vincent T. Covello, *Message Mapping*, WHO 2002 (stakeholders first; “O” map of what people must know *regardless of the question*; mental noise can cut processing **>80%**; 3 messages, each **<9 words / <3 seconds**). Operator use is the weekly named-person map, not a bioterror press conference.

If they want a message-mapping lecture: one paragraph then produce or stop.

## When to use

- Several named humans must hear the same core this week, with different emphasis
- One “stakeholder update” is about to be BCC’d
- Two drafts already disagree on a fact, a commitment, or severity

## When not to use

- Who believes / who blocks; 10-day conversations — [Stakeholder Alignment](../../management/stakeholder-alignment/SKILL.md)
- Who has the D — [Decision Rights](../../management/decision-rights/SKILL.md)
- Who does the work — [RACI Delivery](../../project/raci-delivery/SKILL.md)
- Manager retell after a decision — [Cascade Script](../../comms/cascade-script/SKILL.md)
- First-hour incident statement — [Crisis Holding](../../writing/crisis-holding/SKILL.md)
- Thesis / what we publish when — [Thought Leadership Thesis](../../branding/thought-leadership-thesis/SKILL.md) / [Editorial Calendar](../../branding/editorial-calendar/SKILL.md)
- Rows that are functions (“Finance”) with no named human — refuse

## Modes

| Mode | When | Output |
|---|---|---|
| **produce** | Default. Named people + a locked core | O-map + one row each + variance ledger + send ASK |
| **redline** | They pasted one paragraph for everyone, or two conflicting versions | Lock facts; split emphasis; kill function-rows |
| **refuse** | No named humans; RAPID/RACI asked; same paragraph BCC | Issues list. Stop |

## Hard rules

1. Clock is **this week**. A map in a folder is not this week’s map.
2. Lock the **O-map first**: 3 phrases that may be quoted against each other. If legal/IR has a register, copy it verbatim.
3. Facts / commitments / **severity** identical across rows. Emphasis / detail / **ask** may vary.
4. One **named** person per row. Not a persona. Not a function.
5. One sentence each. If you cannot say it in **9 words**, you do not yet know the message.
6. Variance ledger: EMPHASIS / DETAIL / ACTION (allowed) vs FACT / COMMITMENT / SEVERITY (error — stop).
7. Write as if **screenshotted**. Two versions that disagree on a fact are a leak.
8. Channel is the one they will actually open. A BCC of one paragraph is not a map.
9. Do not invent names, facts, or asks. Holes stay holes.

## Intake

If **the locked 3 core phrases** and **at least two named people** are both missing after one round: issues list, not a fake map.

1. The event / issue this week, in one line (load-bearing)
2. Three locked phrases (fact / commitment / severity) — verbatim (load-bearing with 1)
3. Named people (not functions): role, what they need, the ask of them or “none”
4. Channel + sender each will actually open
5. Date this week for each send
6. Two questions each person will ask next
7. Owner of each send; legal/IR register Y/N

## Output shape

```
THIS-WEEK MESSAGE MAP  |  [issue]  |  week of: [date]
O-MAP (verbatim in every version — do not rewrite)
1. [≤9 words]
2. [≤9 words]
3. [≤9 words]

| Person (named) | One sentence this week | Ask of them / none | Channel + sender | Send date | Next 2 Qs | Owner |
| [Name, title] | [ ] | [ ] | [email / slack — from X] | [date] | 1.  2. | [ ] |

VARIANCE LEDGER
| What differs | Class: EMPHASIS / DETAIL / ACTION (ok) or FACT / COMMITMENT / SEVERITY (error) |
If any FACT / COMMITMENT / SEVERITY differs: STOP. You have a leak, not a map.

NOT THIS PAGE: RAPID → decision-rights; who-blocks → stakeholder-alignment; manager retell → cascade-script

ASK: send every row by [date this week]. Owner: [ ]. Date: [ ].
HOLES: [ ]
```

## QA (must pass)

1. O-map is 3 phrases, each ≤9 words, identical across rows.
2. Every row is a named human, not a function.
3. One ASK + owner + date this week.
4. Variance ledger present; no FACT/COMMITMENT/SEVERITY drift.
5. Not RAPID, not RACI, not stakeholder-alignment, not crisis-holding.
6. No invented names or facts.

If 1, 2, 3, or 4 fail: do not ship.

## Escalate / stop

- Same paragraph BCC’d → refuse; split rows.
- Two versions disagree on a fact → stop; relock the O-map.
- Function-only rows → refuse until names exist.
