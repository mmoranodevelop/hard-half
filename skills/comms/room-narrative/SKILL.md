# Room Narrative

**ROOM NARRATIVE — spoken spine, 8–12 minutes, interruptible.** One page they can hold, not a script to recite. Default: venture exec/program hour after a pre-read. Same spine for F500 ELT. 8 minutes default; 12 is the ceiling.

Method origin: Duarte sparkline used as **business contrast** (what is → what could be), not a TED arc + Army/Air Force BLUF for the first 20 seconds + Amazon/Jassy: after a narrative the meeting is for **Why questions**, not a second presentation. Pyramid supplies the governing thought — [Pyramid Principle](../../writing/pyramid-principle/SKILL.md) — then this page.

If they want a TED/sparkline lecture: one paragraph then produce or stop.

## When to use

- Pre-read exists (or you admit this is a working session, not a narrative)
- You have 8–12 minutes before interrogation
- The draft is a tour of the appendix, a founding story, or a 30-minute slide novel

## When not to use

- Company / program all-hands after a decision — [All-Hands](../../writing/all-hands/SKILL.md)
- Hostile questions written in advance — [Board Q&A Prep](../../writing/board-qa-prep/SKILL.md)
- Designed social posts — [Social Carousel](../../branding/social-carousel/SKILL.md)
- The 2–5 page pack *before* the room — [Pre-Read](../../comms/pre-read/SKILL.md)
- Spoken board 8 min (directors as directors) — [Board Spoken](../../comms/board-spoken/SKILL.md)
- Live hostile session under fire — [Hostile Room](../../comms/hostile-room/SKILL.md)
- Duarte-as-TED / I Have a Dream as an ELT hour — refuse

## Modes

| Mode | When | Output |
|---|---|---|
| **produce** | Default. Sitting dated; a governing thought exists | One-page spoken spine + one ASK |
| **redline** | They pasted a script or a live deck | Cut tour/TED; restore BLUF + 3 beats + ask |
| **refuse** | Reading the pre-read aloud; no sitting; TED keynote | Issues list. Stop |

## Hard rules

1. Clock is **the spoken 8–12 minutes**. The pack is a different object. Do not read it aloud.
2. First **20 seconds**: BLUF + the ask of this room.
3. **Three beats only**: what is → complication → what must be true if they decide. Close on the ask. No many-peak TED sparkline.
4. **One number** the room can remember. One visual maximum. Detail lives in the pre-read.
5. Time marks on the page. Time it standing up.
6. Name the one thing you will **not** discuss here (parked to Q or to the pre-read).
7. If no pack exists, write [Pre-Read](../../comms/pre-read/SKILL.md) first or label this a working session.
8. Do not invent numbers. Holes stay holes.

## Intake

If **sitting date + slot minutes** and **the ask of this room** are both missing after one round: issues list, not a fake spine.

1. Meeting; date; minutes you actually get (load-bearing)
2. Pre-read exists? Y/N — if N, working session or write the pack first
3. Governing thought + the ask of this room (load-bearing with 1)
4. What is / the complication / what could be if they decide
5. The one number they should remember — or hole
6. What you will not discuss here
7. Speaker; one visual Y/N

## Output shape

```
ROOM NARRATIVE  |  [meeting]  |  sitting: [date]  |  slot: [8–12] min
Speaker: [ ]     Pre-read: exists / working-session (labelled)
Visual: none / one ([what])

0:00–0:20  BLUF + ASK
[one sentence governing thought]. Ask of this room: [decide / discuss / note X].

BEAT 1  what is (shared, not theatre)     ~2 min
[ ]

BEAT 2  the complication                   ~3 min
[ ]

BEAT 3  what could be if they decide       ~3 min
[ ]

THE NUMBER  [one figure they can repeat]
PARKED  [topic] → Q cards / pre-read / later sitting

0:last-30s  ASK RESTATED
ASK: [ ]     Owner: [ ]     Date: [ ]
HOLES: [ ]
```

## QA (must pass)

1. 8–12 minutes with time marks. Not a 30-minute slide tour.
2. BLUF in the first 20 seconds. Three beats, not a TED arc.
3. One ASK + named owner + sitting date.
4. Not the pre-read read aloud. Not all-hands. Not board-spoken. Not Q cards.
5. One number (or a labelled hole). One visual max.
6. No invented numbers.

If 1, 3, or 4 fail: do not ship.

## Escalate / stop

- Reading the pre-read aloud → refuse.
- All-hands / TED / social carousel → route.
- Room already hostile and cards exist → [Hostile Room](../../comms/hostile-room/SKILL.md); keep this spine, do not abandon it.
