# Objection Map

**Objection Map — Named Objection / Next Line / Owner** — one page: rows = objections in their words + type (Need / Urgency / Trust / Money / Indecision); columns = next line we will actually say or send, proof or trade attached, seller-side and buyer-side owner, status (open / confirmed closed). Biggest barrier at the top. Default: venture (few voices; still name the person). Same spine for F500 (more rows; same three columns).

Method origin: RAIN Group (training vendor) Listen–Understand–Respond–Confirm + Gong (vendor) pause-after-objection + JOLT (training vendor) for indecision vs status-quo. https://www.rainsalestraining.com/blog/4-steps-to-handle-sales-objections

If they want an objections lecture: one paragraph then produce or stop.

## When to use

- A live meeting this week produced pushback in their words
- Price is being treated as the objection without a type label
- An objection went unanswered and will resurrect off the call
- Status-quo pitch is being doubled against what may be indecision

## When not to use

- Interpersonal conflict — [Difficult Conversation](../../writing/difficult-conversation/SKILL.md)
- Delivery / account incident — [Client Escalation](../../accounts/client-escalation/SKILL.md)
- One named discount vs list — [Discount Exception](../../strategy/discount-exception/SKILL.md)
- Give/get table once we are trading — [Negotiation Trades](../../comms/negotiation-trades/SKILL.md)
- Non-standard package — [Deal Desk](../../commercial/deal-desk/SKILL.md)
- The live close sentence — [Close Ask](../../comms/close-ask/SKILL.md)

## Modes

| Mode | When | Output |
|---|---|---|
| **produce** | Default. At least one named objection in their words | Map + next-line ASK |
| **redline** | They pasted “they’re hesitant” or a rebuttal script | Force quote + type + next line + owner |
| **diagnose** | Unclear whether the stall is objection, indecision, or wrong buyer | Label the type; do not write a price fight |
| **refuse** | Two of named objection / next line / owner / type missing; or they want a therapy memo | Issues list. Stop |

## Hard rules

1. Clock is **this week’s next line**. Person + date + the sentence. Empathy-without-a-line is not the map.
2. Quote their words. “They’re hesitant” is not a named objection.
3. Type every row: **Need / Urgency / Trust / Money / Indecision** (RAIN four types, training vendor, plus JOLT indecision). Address the biggest barrier first. Restate; then “What else?” — often the last one is real. Money is often a red herring.
4. **Do not drop price in a vacuum.** Trade, or route to [Negotiation Trades](../../comms/negotiation-trades/SKILL.md) / [Discount Exception](../../strategy/discount-exception/SKILL.md). This map does not grant discount.
5. JOLT (training vendor): **40–60%** of deals lost to no-decision; of those, **44%** status quo / **56%** indecision. Doubling down against status quo when the problem is indecision **backfires 84%**. Next line for indecision is Judge / Offer recommendation / Limit exploration / Take risk off the table — not more features.
6. Gong (vendor): top reps pause **5×** longer after an objection; unsuccessful speed up **173 → 188 WPM**. The next line is calm.
7. Owner column is load-bearing. Salesforce State of Sales 6th ed.: an **objection that went unanswered** is a coachable miss. Confirm-closed is a *buyer* sentence.
8. Name the person. A Talker’s pushback is not a Blocker’s veto. Do not invent quotes.

## Intake

If **two** of 1–4 are missing after one round: issues list, not a fake map.

1. At least one objection in the buyer’s words (quote) — load-bearing
2. Next line (the actual sentence) — load-bearing
3. Owner who will deliver that line this week — load-bearing
4. Type label (Need / Urgency / Trust / Money / Indecision) — load-bearing
5. Proof or trade attached, or “none — do not invent”
6. Buyer-side counterpart (who must confirm it closed)
7. Biggest barrier ranked

## QA (must pass)

1. At least one quoted objection, not “hesitant.”
2. Next line is a sentence we will say or send.
3. Named owner + date this week.
4. Type labelled; indecision not treated as a price fight.
5. No vacuum discount granted on this page.
6. Not a difficult-conversation memo, escalation log, or discount ticket.
7. One page.

If 1, 2, 3, or 5 fail: do not ship.

## Escalate / stop

- Answer in the first second / drop 10% in the room → refuse.
- Two of quote / next line / owner / type missing → issues list.
- They want a methodology class → one paragraph then produce or stop.
- Price exception needed → [Discount Exception](../../strategy/discount-exception/SKILL.md); trades → [Negotiation Trades](../../comms/negotiation-trades/SKILL.md).
