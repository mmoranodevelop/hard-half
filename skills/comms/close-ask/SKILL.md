# Close Ask

**Close Ask — This Week + Next Paper Step** — one page: the ask in one sentence with a day this week, SPIN outcome targeted (Order vs Advance — never Continuation), next paper step (MSA / security / vendor form / PO) with named buyer owner, fallback Advance that is still a buyer action, risk-off-the-table if indecision is the diagnosis, what “no” looks like. Default: venture (founder can often Order). Same spine for F500 (Advance to paper is the usual win).

Method origin: SPIN Obtaining Commitment (Order / Advance / Continuation / No-sale) + MEDDICC (training vendor) Paper Process + JOLT (training vendor) when the stall is indecision. https://www.huthwaiteinternational.com/spin-methodology

If they want a closing / SPIN / MEDDICC lecture: one paragraph then produce or stop.

## When to use

- A live call this week needs a dated ask, not “I’ll send something”
- Verbal yes exists and paper (legal / security / MSA) is unnamed
- The last ending was a Continuation and we are congratulating ourselves
- Indecision (not a true objection) is the stall

## When not to use

- Candidate / employment offer — [Offer Conversation](../../writing/offer-conversation/SKILL.md)
- Multi-step joint Gantt — [Mutual Action Plan](../../accounts/mutual-action-plan/SKILL.md)
- Weekly Commit number — [Forecast Call](../../commercial/forecast-call/SKILL.md)
- Non-standard terms yes/no — [Deal Desk](../../commercial/deal-desk/SKILL.md)
- Named objections + next line — [Objection Map](../../comms/objection-map/SKILL.md)
- Sendable recap of the ask — [Follow-Up 48h](../../comms/follow-up-48h/SKILL.md)

## Modes

| Mode | When | Output |
|---|---|---|
| **produce** | Default. Dated ask and paper step (or labelled unknown) are writable | Ask page + ASK |
| **redline** | They pasted “I’ll send a proposal and check in” | Relabel Continuation; force a buyer action |
| **diagnose** | Stall unclear: objection vs indecision vs missing paper | Name the stall; do not hard-close |
| **refuse** | Two of dated ask / paper step+owner / fallback Advance / Order-vs-Advance label missing | Issues list. Stop |

## Hard rules

1. Clock is **this week’s sentence**. Day, not “soon.” Person + date + yes/no or paper step.
2. SPIN / Rackham (Huthwaite training vendor; HubSpot public summary): every call ends **Order / Advance / Continuation / No-sale**. An Advance is a *buyer* action. A Continuation (“send me something, we’ll see”) is a **failed close**. Aggressive closes **backfire in major sales**.
3. Next paper step is named (MEDDICC training vendor: Process / People / Timing after decision). “You cannot accurately forecast without fully understanding the Paper Process.” If paper is unknown, do not ask for a signature — run [Discovery Call](../../comms/discovery-call/SKILL.md) / [Economic Buyer](../../comms/economic-buyer/SKILL.md).
4. MEDDICC (training vendor): **60%** of deals lost to inertia; engagement ≠ progress.
5. JOLT (training vendor): **40–60%** of deals lost to no-decision; of those **44%** status quo / **56%** indecision. Offer a recommendation; Limit exploration; Take risk off the table (phased, opt-out, realistic TTV — optimistic TTV *increases* indecision). Dixon interview (CustomerThink): moderately indecisive convert **26%** average vs **58%** high performers; highly indecisive **6%** vs **31%**.
6. Reserve time to say it (Gong vendor: ~**4 minutes** next steps; Sandler UFC, training vendor, at the open). CEB 2016: **Prescribe**.
7. Fallback Advance is still a buyer action. “No” is a clean no-sale, not a ghost.
8. Do not invent paper owners or dates. Holes stay holes.

## Intake

If **two** of 1–4 are missing after one round: issues list, not a fake ask.

1. Dated this-week ask (day, not “soon”) — load-bearing
2. Next paper step with named buyer-side owner, or “paper unknown — do not ask for signature” — load-bearing
3. Fallback Advance that is still a buyer action — load-bearing
4. Order vs Advance vs Continuation labelled — load-bearing
5. Indecision vs true objection (if indecision: risk-off-the-table offer)
6. What “no” looks like
7. Who says the ask on the call

## Output shape

```
CLOSE ASK — THIS WEEK + NEXT PAPER STEP  |  [account]  |  call: [day]  |  said by: [name]
Primary ask (one sentence, a day this week): [ ]
SPIN target: Order / Advance     NEVER: Continuation

NEXT PAPER STEP (MEDDICC P — process / people / timing)
Step: [MSA / security questionnaire / vendor form / PO / other]
Buyer owner: [name]     Date: [day]     If paper unknown: do not ask for signature

FALLBACK ADVANCE (buyer action if they decline the primary)

Recommendation: [one path]     Risk off table: [phased / opt-out / realistic TTV]
What “no” looks like: [clean no-sale]

NOT THIS PAGE: candidate offer → offer-conversation; joint Gantt → mutual-action-plan; Commit call → forecast-call; terms package → deal-desk

ASK: [speaker] says the primary ask on [day]. Paper owner [buyer] by [date].
Owner: [ ]  Date: [ ]
Holes: [ ]
```

## QA (must pass)

1. Ask has a day this week.
2. Next paper step has a named buyer owner — or explicit “unknown, do not signature-ask.”
3. Fallback is a buyer action, not another email we send.
4. Continuation is labelled failure if that is what happened.
5. ASK + owner + date.
6. Not a MAP, forecast call, candidate offer, or deal-desk ticket.
7. One page.

If 1, 2, 3, or 4 fail: do not ship.

## Escalate / stop

- “I’ll send a proposal and check in” → refuse (Continuation + inertia).
- Two load-bearing fields missing → issues list.
- Hard-close a major deal → refuse (Rackham: backfires).
- They want a methodology class → one paragraph then produce or stop.
