# Discovery Call

**Discovery Call Notes — Pain / Paper Process / Metrics / Economic Buyer** — one page from *this* call: attendees + date, implicate-level pain, their metric (M2 draft), paper process or labelled unknown, suspected Economic Buyer with evidence, buyer-owned next step this week. Default: venture (founder often *is* the EB — still write the evidence). Same spine for F500 (EB hypothesized, not assumed).

Method origin: MEDDICC (training vendor) Pain / Metrics / Paper Process / Economic Buyer + SPIN/Huthwaite (training vendor). https://meddicc.com/what-is-meddpicc/implicate-the-pain

If they want a SPIN / MEDDICC / SPICED lecture: one paragraph then produce or stop.

## When to use

- One live call this week, and commercial facts must land on a page
- Pain is still a topic list; consequence and owner not captured
- Paper process (legal / security / MSA) unknown, and engagement is being treated as progress
- Suspected EB must be named before a 30-minute EB meeting

## When not to use

- Whether to pursue at all — [Bid No-Bid](../../commercial/bid-no-bid/SKILL.md)
- After the outcome — [Win Loss](../../strategy/win-loss/SKILL.md)
- Job statement / forces of progress — [Jobs To Be Done](../../strategy/jobs-to-be-done/SKILL.md)
- Joint close plan on a deal already chosen — [Mutual Action Plan](../../accounts/mutual-action-plan/SKILL.md)
- Weekly Commit number — [Forecast Call](../../commercial/forecast-call/SKILL.md)
- The 30-minute meeting *with* the EB — [Economic Buyer](../../comms/economic-buyer/SKILL.md)
- Sendable recap — [Follow-Up 48h](../../comms/follow-up-48h/SKILL.md)

## Modes

| Mode | When | Output |
|---|---|---|
| **produce** | Default. One call; at least three of pain / metric / paper / EB exist or are labelled unknown | Notes + buyer-owned ASK |
| **redline** | They pasted a SPIN worksheet, CRM dump, or feature recap labelled “discovery” | Force four fields; kill lecture |
| **refuse** | Two of pain / metric / paper / EB missing with no labelled unknown; or they want a class | Issues list. Stop |

## Hard rules

1. Clock is **this call, this week**. Person + date + yes/no, ask, or number. A methodology dump is not notes.
2. Pain must reach **implicate** (MEDDICC, training vendor: Identify → Indicate → Implicate). A topic list is not pain.
3. Metric is *their* number (M2 draft). Brochure M1 is a probe only. Salesforce State of Sales 6th ed.: **86%** more likely to buy when vendors understand objectives; **59%** say most reps don’t.
4. Paper process = Process / People / Timing after verbal yes. MEDDICC (training vendor): **60%** of deals lost to inertia; engagement ≠ progress. “Unknown — [owner] finds it” is allowed; silence is not.
5. Economic Buyer is named or hypothesized with evidence. Do not pretend the 30-minute meeting already happened — that is [Economic Buyer](../../comms/economic-buyer/SKILL.md).
6. Gong (vendor, 2025, 326K calls ≥10 min): closed-won talk **57%**, lost **62%**; winners **15–16** questions, losers ~**20**. Discovery sweet spot **11–14**; C-suite drops after ~**8**, optimal ~**4**. Huthwaite/SPIN (training vendor): **35,000+** observed calls.
7. Next step is **buyer-owned** this week. “We’ll send a deck” is a Continuation, not discovery complete.
8. Do not invent pain, metrics, paper steps, or names. Holes stay holes.

## Intake

If **two** of 1–4 are missing after one round (and not labelled unknown): issues list, not a fake page.

1. Call date + buyer attendees (names + titles) — load-bearing
2. Pain in *their* words: consequence + who owns it — load-bearing
3. Metric they care about, or “unknown — next question is ___” — load-bearing
4. Paper process (steps / people / timing) or explicit unknown with finder — load-bearing
5. Suspected EB + evidence, or Champion-test: will they introduce?
6. What we will *not* pitch next
7. Buyer-owned next step + date this week

## Output shape

```
DISCOVERY CALL NOTES  |  [account]  |  date: [day]  |  attendees: [names / titles]
Clock: this call     D on next step: [buyer name]

PAIN (implicate, their words)
[consequence]     Owner of the pain: [name]     If we do nothing: [ ]

METRICS (their number — M2 draft; M1 only as a probe)
What they measure: [ ]     Window: [ ]     Unknown → next question: [ ]

PAPER PROCESS (after verbal yes → signature)
Process: [legal / security / vendor form / MSA / unknown]
People: [names]     Timing: [ ]     Finder if unknown: [owner + date]

ECONOMIC BUYER (suspected — evidence, not the 30-min meeting)
Name / title: [ ]     Evidence of veto / P&L: [ ]
Champion will introduce? Y/N     If N → not a Champion yet

NOT THIS PAGE: pursuit gate → bid-no-bid; job statement → jobs-to-be-done; joint Gantt → mutual-action-plan; Commit → forecast-call; meeting with EB → economic-buyer

ASK (buyer-owned this week): [one sentence]
Owner: [buyer]  Date: [day]  Yes/no or number: [ ]
Holes: [ ]
```

## QA (must pass)

1. Four fields present or labelled unknown — if two missing, do not ship.
2. Pain has consequence + owner, not a topic list.
3. One ASK + named buyer owner + date this week.
4. No invented names, metrics, or paper steps.
5. Not a bid gate, JTBD interview, MAP, forecast, or EB agenda.
6. One page.

If 1, 3, or 4 fail: do not ship.

## Escalate / stop

- They want SPIN / MEDDICC / SPICED taught → one paragraph then produce or stop.
- Two of pain / metric / paper / EB missing → issues list.
- Feature dump / product monologue as “discovery” → refuse.
- They want a pursuit gate → [Bid No-Bid](../../commercial/bid-no-bid/SKILL.md).
