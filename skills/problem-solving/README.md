# problem-solving

Problems that are stuck — derive rather than retrieve. Also: candidates that look like value and may not be. Also: the five ways a default solver still fails after those three — wrong problem, eaten fix, empty AND, adaptive player, missing coordinate.

## Model-invoked

Reachable by you *or* selected automatically by the agent when a task matches.

- [`first-principles`](first-principles/SKILL.md) — Attack a problem that is stuck — every known approach tried, the accepted answer is "impossible with current technology", or the cost, physics, or scale numbers refuse to work.
- [`value-problem-solver`](value-problem-solver/SKILL.md) — Run a product idea, feature, PRD, vendor proposal, or initiative through seven value filters and produce an Audit verdict or a Design walk before anyone writes the spec.
- [`verified-hard-problem`](verified-hard-problem/SKILL.md) — Attack one locked unsolved claim (millennial, prize-grade, safety, legal-grade) with lemma swarm and a verification gate; refuse unverified "solved".
- [`ghost-problem`](ghost-problem/SKILL.md) — Prove the stated problem is load-bearing, or name the problem whose death would make this one evaporate.
- [`cobra-equilibrium`](cobra-equilibrium/SKILL.md) — Before a metric, incentive, or agent reward ships, write how the measured system will eat it, then survive or refuse.
- [`empty-and`](empty-and/SKILL.md) — Prove or kill the claim that several locally-working solutions can coexist; find the empty intersection.
- [`red-queen`](red-queen/SKILL.md) — Treat the problem as a player that updates when you move; name half-life, then equilibrium or an arms-race stop.
- [`missing-axis`](missing-axis/SKILL.md) — Find the measurable coordinate the current search space does not have, so every incumbent option is the same option written differently.
