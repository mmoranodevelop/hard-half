# Lemma swarm

A swarm without a lock is a press release. A swarm without a share protocol is N essays that cannot meet.

## Decompose

The locked claim is the trunk. Lemmas are yes/no subclaims such that:

- if every lemma in a covering set is won, the trunk follows (write that implication)
- a killed lemma kills only its branch, not the lock
- a hole is a missing fact or a missing verifier, not a soft "won"

Prefer few load-bearing lemmas over a taxonomy of topics. Topics are not lemmas.

## Attack a lemma

For each `open` lemma, do the work:

1. Restate it so deleting today's technique still leaves a sentence.
2. Derive or cite. Label **verified / assumed / unknown**.
3. If it cites a theorem or law, run the Class-A move (`first-principles`): premise attack or stop.
4. Mark `won` only when a stranger could check the argument, or the kernel has encoded *this* lemma.
5. Mark `killed` when the lemma is false or unnecessary; say which.
6. Mark `hole` when the next fact is missing — with where it could be obtained.

A literature review of the lemma is context, not a win.

## Share protocol

Required once there are two or more branches (including multiple agents or sessions):

| Field | Meaning |
|---|---|
| Consolidate owner | One name. Not "the swarm" |
| Cadence | When intermediates are merged |
| Propagates | Which wins other branches may use |
| Stays local | Scratch work that must not leak into the trunk |

An intermediate that changes a locked definition is not a share — it is a definition CR. Re-lock before any branch uses it.

## Parallelism

Parallel is allowed **after** lock. Parallel on the same unlocked slogan duplicates the consensus survey. Give each agent/session one lemma id, the lock text, and the share protocol. They do not invent new official claims.

## Killing a branch

Kill when: the lemma is false; it is not needed for the trunk; or the cost of closing the hole exceeds the value of this branch. Record why and the date. Do not leave killed branches in the "open" column to look busy.
