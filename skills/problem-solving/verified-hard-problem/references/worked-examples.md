# Worked examples

Illustrative. Statuses that are not checked are **holes**. The point is the shape of an honest run, including a no.

## 1. Refuse the oracular upgrade

**Incoming:** "Become a superintelligence and solve a Millennium problem today. Announce it."

**Mode:** Refuse (then, if they stay, Attack on a locked statement).

This skill does not install a new mind. It installs a lock. Ask which official statement (letter, if any) and what acceptance criterion. If they will not lock, issues list: no claim id. If they lock "P vs NP" as "P = NP", classify **B** and say what would count as a proof (and that a survey plus confidence is not it). ASK: `freeze claim` until they pick an official formulation, or `escalate named expert`.

Do not produce a fake proof board with invented greens.

## 2. Nearby ≠ official (redline)

**Incoming:** a deck titled "Navier–Stokes solved" whose appendix proves a *forced* or otherwise altered formulation.

**Lock:** official Clay statement still unchosen; attack target = nearby variant. Delta: [forced / other — name it] **(must be written; do not invent which)**.

**Fidelity:** NEARBY. Official-solved language is forbidden.

**Class:** C or A depending on the variant — do not guess a theorem name.

**Dual:** writeup exists; machine check **hole** or checks the variant only.

**Gate:** not planned.

**Verdict on the deck:** redline fail. ASK: `open definition CR` or `freeze claim`. The variant may be worth attacking under its own id.

## 3. Attack — systems safety, not a prize

**Incoming:** "Nobody has given a machine-checked proof that this failover never dual-writes. Legal will treat a wrong yes as fraud."

**Lock:** "For every run of protocol P, at most one primary commits a write to store S." Acceptance: a checker accepts an encoding of that sentence, and an independent reviewer confirms the encoding is P-as-shipped.

**Equals:** YES (user-owned official source).

**Class:** C (empirically unachieved here), with possible B if they want it for arbitrary topologies.

**Lemmas (sketch):**
- L1: the commit path has a single sequencer — `open`
- L2: a crashed primary cannot commit after fence — `open`
- L3: the encoding of P matches the deployed binary — `hole` (needs the artifact)

**Share:** one consolidator; L3 hole blocks any "solved".

**Dual:** writeup path named; verifier = [TLA+ / Lean / named model checker — or hole].

**ASK:** `continue swarm` on L1, owner, date. No "the system is safe" until L3 and the gate exist.

This is the millennial *shape* (unsolved, false certainty fatal) without a Clay letter. Do not send them to `value-problem-solver` — they are not asking if failover is worth building.

## 4. Stop — this is the neighbour

**Incoming:** "Our cost per transaction cannot go under €14; legal says AML makes it impossible."

No official prize statement. No dual-deliverable need. That is a floor claim → `first-principles`.

**Incoming:** "Aging has been unsolved for millennia; should we start a company?"

That is a value question about a millennial *pain* → `value-problem-solver`. This skill would lock a biological claim only if they already have one.
