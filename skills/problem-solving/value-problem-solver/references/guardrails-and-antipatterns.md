# Guardrails and anti-patterns

Guardrails fire **before** optimization. A violation is a veto. Do not "weigh" it against a strong filter 2.

## The seven vetoes

1. **No hidden harm.** If your value depends on someone not knowing what you are doing to them, it is not value.
2. **Real consent.** Whoever bears a cost knows and accepted it freely. Unreadable terms are not consent.
3. **Reversibility.** Prefer what you can undo. Irreversible harm demands a certainty you almost never have. When uncertain, take the action that leaves more options open.
4. **Aligned incentives.** You earn when the user is better off — not when they are worse, not when they cannot leave.
5. **Headline test.** If the way you create or capture value ran on the front page, described accurately, would that be a problem? Then it is a problem now.
6. **Time test.** In ten years, is this remembered as an improvement or as something tolerated until the cost became visible?
7. **Truth in the metric.** Do not optimize a proxy without a scheduled check that it still tracks the real wellbeing. Goodhart is how filter 7 dies quietly.

If a veto fails, the honest outputs are: stop; or redesign so the violation is gone. A footnote is not a redesign.

## Things that look like value and are not

| Looks like value | Actually is | How to see it |
|---|---|---|
| More features | Complexity that cuts adoption | People use ~10% of them |
| Fast subsidized growth | Value borrowed from the future | The model does not stand without the subsidy |
| High engagement | Attention capture, not wellbeing | Users say they want to use it less |
| Low price via offloaded cost | Cost transferred to someone else | The payer is not the beneficiary |
| Solving a problem I have | Projection, not research | Nobody else recognizes it unprompted |
| Brilliant technical novelty | Solution looking for a problem | The work started from the technology, not the job |
| Strong lock-in | Capture without creation | People stay because leaving hurts, not because staying is better |
| Optimizing the metric | Goodhart: the proxy ate the goal | The metric rises; wellbeing does not |

When a row matches, name it on the page. Do not translate it into a softer filter-2 success.
