# Fundraising One-Pager

A **process 1-pager** to raise: how much, what it buys, which instrument, which names, which weeks. Default: venture seed / Series A. This is the operating plan for the raise, not the story you tell in the room.

Public method: YC seed guide (Ralston) — raise to the next fundable milestone (often 12–18 months), dilution usually ≤20–25%; Harris / Holloway **parallel** process (first meetings in one window, not serial); First Round public "horse race" — batch, pulse, force a clock. Reconstruct the plan. Do not write their pitch.

## When to use

- "We need to raise — how much, from whom, by when?"
- Before outreach: lock amount, use, list, calendar
- A raise that is drifting serial (one fund at a time)
- Board / chair wants the process, not another deck

## When not to use

- The **pitch** or leave-behind narrative (write that elsewhere; this page does not become a deck)
- Monthly letter to existing holders — [Investor Update](../../writing/investor-update/SKILL.md)
- A paper already on the table — [Term Sheet Read](../../strategy/term-sheet-read/SKILL.md)
- 13-week cash / runway math as the whole job — [Cash Runway](../../management/cash-runway/SKILL.md) (runway **feeds** the amount)
- An F500 budget ask — [Business Case](../../strategy/business-case/SKILL.md)

If they want "write the deck", refuse this skill as the author; offer the process page plus holes for the deck owner.

## Modes

| Mode | When | Output |
|---|---|---|
| **produce** | Default | Process 1-pager: amount, use, list, timeline, ASK |
| **redline** | They pasted a "we're raising $X" email | Same facts; add use, list, parallel clock |
| **refuse** | No amount logic, or they want a pitch-writing class | Issues list or one paragraph then stop |

## Hard rules

1. **Amount is earned by a milestone**, not a round number. YC: raise to profitability *or* to the next fundable proof in 12–18 months. Work backwards from burn × months + buffer. If burn is unknown, hole — do not invent.
2. **Use of funds maps to that milestone.** Product / GTM / team / buffer in $ and in *what it buys*. "Operations 20%" is a fail.
3. **Instrument named.** SAFE (cap, discount, MFN?) vs priced (lead needed). Do not mix "we'll see" on page 1.
4. **Dilution band.** Target and walk-away (YC public: try ≤20%, avoid >25% at seed unless you say why).
5. **Parallel, not serial.** First meetings in a 1–3 week window. Serial lets funds wait on each other (Harris).
6. **Named list, ranked.** Lead-capable vs follow. Warm intro path.  A/B/C. A list of "VCs in general" is not a list.
7. **Clock.** Prep done before send. Term-sheet date. Start while runway still gives leverage (do not start at 4 months cash).
8. **One ASK.** Open the process / delay / do not raise. Owner (usually CEO), date.
9. **Do not write the pitch here.** Link the deck owner. This page is amount, use, who, when.
10. **One page.** Investor CRM can be an appendix table.

## Intake

Refuse a FOR-SENDING process page if amount *and* milestone are both missing. Two load-bearing holes → issues list.

1. **Milestone this raise must buy** and by when
2. **Current cash, burn, runway** (or a hole)
3. **Amount range** they will actually accept
4. **Instrument** they will offer
5. **Lead vs follow** names they can introduce
6. **Date they must have money in** (payroll, vendor, board)

## Workflow

1. Reverse: milestone → months → burn → amount + buffer.
2. Split use of funds into 3–5 buckets tied to the milestone.
3. Pick instrument. If priced, name the lead job.
4. Build A/B/C list with intro path. Count lead-capable names; if <5, that is the issue.
5. Draw the parallel calendar (prep / firsts / partners / sheet / close).
6. ASK.

```markdown

ASK: [CEO] to [open / delay / not raise] by [date]
Milestone this money buys: … by …

## Amount and use
- Cash now / net burn / runway: …
- Raise: [$ ]  →  [n] months to milestone (incl. raise time)
| Bucket | $ | What it buys (observable) |
|---|---|---|
| | | |

## Who
| Name / fund | Lead? | Check size | Intro path | Status |
|---|---|---|---|---|
| A … | | | | |
Lead-capable count: [n]  Hole: …

## Timeline (parallel)
- Prep done: [date] (deck owner: … — not this page)
- First meetings: [week range]
- Partner / diligence: [week range]
- Term sheet target: [date]
- Money in: [date]

## What we will not do
- Serial one-fund-at-a-time
- Start at <[n] months cash without saying we are weak

## ASK
[one sentence]
```

## QA (must pass)

1. Amount tied to a named milestone and months, or a hole on burn.
2. Use of funds in $ *and* observables, not % theatre.
3. Instrument named.
4. Dilution band + walk-away.
5. Named investors, lead-capable counted.
6. Parallel calendar with a term-sheet date.
7. One ASK, owner, date.
8. Not a pitch deck.
9. Not a term-sheet legal read.
10. No invented burn or committed leads.

If 1, 5, 6, or 7 fail: do not ship.

## Escalate / stop

- They want you to write the 12-slide story → refuse; process page only.
- They are out of cash inside the raise time → [Cash Runway](../../management/cash-runway/SKILL.md) first; this page says "raise from weakness".
- A sheet is already in — [Term Sheet Read](../../strategy/term-sheet-read/SKILL.md).
- Securities law, general solicitation, who may invest → counsel.
