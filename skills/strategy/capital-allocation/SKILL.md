# Capital Allocation

**Where next € goes — one page this cycle** — sources, uses ranked (build / buy / hold / return / paydown), opportunity cost, one ASK. Default: MD / CEO capital committee for this quarter or budget cycle; same spine for PE portco cash generation.

Method origin: Buffett/Berkshire public capital-allocation duty + institutional-imperative caution; Mauboussin public uses-of-capital framework (invest / M&A / return / delever); McKinsey public on CEO-led allocation and fighting inertia (last year’s budget ≠ this year’s plan).

If they want a capital-markets lecture: one paragraph then produce or stop.

## When to use

- "We have €X — build, buy, hold, return, or pay down?"
- Annual / quarterly capital committee; inertia is copying last year
- Competing asks (capex vs M&A vs dividend vs debt) need one ranked page
- Post-cash generation: sponsor asks for allocation recommendation

## When not to use

- Single project NPV / options — [Business Case](../../strategy/business-case/SKILL.md)
- 13-week bank survival — [Cash Runway](../../management/cash-runway/SKILL.md)
- 3–4 worlds under uncertainty — [Scenario Planning](../../strategy/scenario-planning/SKILL.md)
- Kill / continue one venture bet — [Kill Criteria](../../strategy/kill-criteria/SKILL.md)
- Lender ratio flash — [Covenant Compliance](../../finance/covenant-compliance/SKILL.md)
- Follow-on yes/no on a round — [Follow On](../../finance/follow-on/SKILL.md)

This page **ranks uses of capital this cycle**. It is not one project’s business case.

## Modes

| Mode | When | Output |
|---|---|---|
| **produce** | Default. Cycle + capital available known | Allocation one-pager + one ASK |
| **redline** | They pasted last year’s budget as "strategy" | Zero-base; force ranked uses; kill inertia copy |
| **refuse** | No capital available figure, no cycle, or "model every project here" | Issues list. Stop |

## Hard rules

1. **Name the cycle** (quarter / FY / post-exit) and **capital available** (cash + undrawn you will actually use — or hole).
2. **Five buckets always considered:** Build (organic / capex / hire) · Buy (M&A / tuck-in) · Hold (liquidity buffer) · Return (dividend / buyback) · Paydown (debt). Explicit "none" is allowed; silence is not.
3. **Rank uses** with € and owner — not a laundry list of equal priorities.
4. **Opportunity cost line:** what you are *not* doing if you fund #1.
5. **Hurdle / test stated** in plain words (ROIC vs WACC, payback, strategic must) — no fake precision.
6. **One ASK** — approve split / defer buy / raise return / accelerate paydown. Owner, date.
7. **Do not invent returns, synergies, or capacity.** Hole: `[business-case by DATE]` for a named buy/build.
8. **Inertia is a fail:** "same as last year" without a because.
9. **Liquidity floor respected** — if bank runway is red, allocation yields to survival ([Cash Runway](../../management/cash-runway/SKILL.md)).
10. **One page.** Deep single invest → business-case.

## Intake

If **two** of 1–3 are missing after one round: issues list, not a fake split.

1. Cycle and decision forum (CEO committee / board / sponsor) — load-bearing
2. Capital available this cycle (and as-of) — load-bearing
3. Candidate uses already on the table — load-bearing
4. Liquidity floor / covenant constraints (pointer)
5. Return policy / leverage target if any
6. The ASK (approve / defer / sequence)
7. What last cycle spent (to fight inertia)

## QA (must pass)

1. Cycle, forum, capital available (or hole).
2. All five buckets addressed (amount or explicit zero).
3. Ranked uses with € and owners.
4. Opportunity cost named.
5. One ASK with owner, date.
6. No invented ROIC / synergies; single big invest pointed to business-case.
7. Not a copy of last year without because.
8. Liquidity floor checked.
9. One page.

If 1, 2, 5, or 6 fail: do not ship.

## Escalate / stop

- Single project needs NPV / options → [Business Case](../../strategy/business-case/SKILL.md).
- Survival liquidity is red → [Cash Runway](../../management/cash-runway/SKILL.md) first.
- They want multi-world novel → [Scenario Planning](../../strategy/scenario-planning/SKILL.md).
- Covenant binds the split → [Covenant Compliance](../../finance/covenant-compliance/SKILL.md).
- No available capital figure after one ask → refuse.
- Tax / securities treatment of return (buyback / dividend) → counsel; do not advise.
