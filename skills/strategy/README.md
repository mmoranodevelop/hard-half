# strategy

Market, competitive, investment, and unit economics.

## Model-invoked

Reachable by you *or* selected automatically by the agent when a task matches.

- [`business-case`](business-case/SKILL.md) — Use when an MD must allocate capital: options including do-nothing, incremental cash, NPV (or honest payback-only), sensitivity, kill criteria, named owner.
- [`capital-allocation`](capital-allocation/SKILL.md) — Use when deciding where the next euro goes this cycle: build / buy / hold / return / paydown — one page.
- [`competitive-teardown`](competitive-teardown/SKILL.md) — Use when tearing down a named rival to decide our move: where they play, how they win, activity-system fit, durable power if citable — then a so-what we will do or refuse.
- [`customer-concentration`](customer-concentration/SKILL.md) — Use when top-N customers are a material revenue or credit risk and an MD needs the math plus what we will do this quarter.
- [`discount-exception`](discount-exception/SKILL.md) — Use for a yes/no on a named discount versus list: fence, expiry, give-get, pocket impact.
- [`experiment-brief`](experiment-brief/SKILL.md) — Use when briefing one experiment: hypothesis, primary metric, sample, kill and scale rules, owner, and dates.
- [`fundraising-one-pager`](fundraising-one-pager/SKILL.md) — Use when an MD must run a raise as a process: amount, use of funds, instrument, who, parallel timeline.
- [`issue-tree`](issue-tree/SKILL.md) — Use when an MD must diagnose a messy problem before anyone writes: one governing question, a MECE tree, a hypothesis, and a starred workplan.
- [`jobs-to-be-done`](jobs-to-be-done/SKILL.md) — Use when you need the customer job and what to stop building: switch interviews, job story, hire/fire.
- [`kill-criteria`](kill-criteria/SKILL.md) — Use when one named venture or bet needs dated kill tests and the next tranche: what must be true, the test, the date, who calls kill.
- [`loi-screen`](loi-screen/SKILL.md) — Use when a named LOI or indication of interest needs a pre-DD go/no-go: strategic fit, valuation-band sanity, deal-breakers.
- [`make-vs-buy`](make-vs-buy/SKILL.md) — Use when choosing how to source a capability: make, buy, partner, kill, or do-nothing.
- [`margin-bridge`](margin-bridge/SKILL.md) — Use when explaining gross or contribution margin this period versus last: three drivers, one action.
- [`market-entry`](market-entry/SKILL.md) — Use when deciding enter this named geo or segment yes/no: first beachhead, entry mode, first cheque, kill test.
- [`okr-cascade`](okr-cascade/SKILL.md) — Use when turning an already-chosen strategy into 3–5 objectives with measurable key results, cascaded from company to a program (not a second strategy).
- [`partner-memo`](partner-memo/SKILL.md) — Use when choosing how to work with a named counterparty: strategic partner vs vendor vs hire.
- [`pr-faq`](pr-faq/SKILL.md) — Use when working backwards from a future customer: a one-page press release dated in the future plus external/internal FAQ, customer as hero, no vanity metrics.
- [`pricing-one-pager`](pricing-one-pager/SKILL.md) — Use when deciding price architecture for an offer: value-based structure, metric, fences, Good-Better-Best.
- [`product-sunset`](product-sunset/SKILL.md) — Use to kill or sunset a product or SKU: customers, revenue, migration, date, message.
- [`scenario-planning`](scenario-planning/SKILL.md) — Use when a material bet faces genuine uncertainty: 3-4 plausible worlds, implications for THIS bet, early indicators.
- [`term-sheet-read`](term-sheet-read/SKILL.md) — Use when an MD must make a business call on a term sheet or SAFE: dilution, control, liquidation at three exits.
- [`unit-economics`](unit-economics/SKILL.md) — Use when an MD must defend whether one more unit (customer, order, SKU, subscription) creates or destroys cash: contribution, payback, cohort vs blended.
- [`win-loss`](win-loss/SKILL.md) — Use when a named deal just closed won or lost and an MD needs why, from the buyer, plus stop/start/continue this quarter.
