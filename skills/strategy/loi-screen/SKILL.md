# LOI Screen

**Pre-DD LOI screen — one page** — named target, strategic fit vs M&A themes, valuation-band sanity (not a full model), deal-breakers, go / no-go / hold-for-data to confirmatory DD, one ASK. Default: corporate or PE buy-side; same spine for sell-side when screening an inbound IOI.

Method origin: McKinsey M&A blueprint / stage-gate screening (themes → outside-in fit → approve-to-negotiate / LOI → confirmatory DD) + Wachtell public deal-process primers (preliminary agreements: NDA / LOI before definitive) + Sullivan & Cromwell public HSR notes (LOI/term sheet as pre-definitive paper must still name scope). Reconstruct the operator screen. Do not practise law.

If they want an M&A process lecture: one paragraph then produce or stop.

## When to use

- An LOI, IOI, or non-binding offer just arrived (or we are about to issue one)
- Before opening confirmatory DD spend / clean team / exclusivity clock
- Strategic fit vs published M&A themes is still a claim, not a page
- Valuation band must be sanity-checked against known comps / prior marks — not a full NPV
- Named deal-breakers must gate "go to DD"

## When not to use

- Business read of a **signed** term sheet / SAFE (dilution, control, waterfall) — [Term Sheet Read](../../strategy/term-sheet-read/SKILL.md)
- Full NPV / options / do-nothing capital case — [Business Case](../../strategy/business-case/SKILL.md)
- Dated kill tests on an **existing** funded bet — [Kill Criteria](../../strategy/kill-criteria/SKILL.md)
- RFP / tender bid yes-no package — [Bid No Bid](../../commercial/bid-no-bid/SKILL.md)
- Post-close integration charter — [IMO Charter](../../ma/imo-charter/SKILL.md)

If there is no named target (or paper), stop. Issues list.

## Modes

| Mode | When | Output |
|---|---|---|
| **produce** | Default. Named target + paper or verbal IOI with price band | Screen card + go/no-go + ASK |
| **redline** | They pasted a "strategic" LOI deck with no fit test | Force themes, band, breakers; kill vibe |
| **refuse** | No target, or "just draft a friendly LOI" with no screen | Issues list. Stop |

## Hard rules

1. **One named target.** Portfolio shopping lists are not this page.
2. **Fit before price.** Map to stated M&A themes / screening criteria (geo, channel, product, size). Gut excitement is not fit (McKinsey blueprint).
3. **Valuation band sanity, not a model.** State offered / implied band vs known public comps, prior mark, or labelled HOLE. Do not invent multiples or synergies.
4. **Deal-breakers are binary.** Regulatory / change-of-control / key-person / IP / customer concentration / culture — each PASS / FAIL / UNKNOWN. UNKNOWN that is load-bearing → hold, not go.
5. **LOI is preliminary.** Binding bits (exclusivity, no-shop, breakup, confidentiality) vs non-binding economics — name which. Counsel owns clause draft; this page owns go/no-go to DD.
6. **DD cost and clock on the page.** What confirmatory DD will cost (time / $ / distraction) and exclusivity end date — or HOLE.
7. **One ASK:** go to DD / no-go / hold-for-data. Owner, date. Next tranche of spend only if go.
8. **Never invent** revenue, EBITDA, multiples, synergy $, or regulatory odds. Holes stay holes.
9. **One page.** Not a CIM rewrite, not a fairness opinion.

## Intake

If **two** of 1–4 are missing after one round: issues list, not a fake screen.

1. Named target + paper type (LOI / IOI / verbal) — load-bearing
2. Stated M&A themes or screening criteria this deal must hit — load-bearing
3. Price / consideration band on the paper (or "none stated") — load-bearing
4. Known financials used for the band (source + as-of) — load-bearing
5. Binding vs non-binding clauses already proposed (exclusivity, break fee)
6. Who owns the go/no-go (MD / IC) and exclusivity / answer date
7. Prior marks, comps, or "none — HOLE"
8. Suspected deal-breakers already flagged

## QA (must pass)

1. Named target and paper type.
2. Fit mapped to stated themes (or HOLE on themes).
3. Valuation band with source or labelled HOLE — no invented multiples.
4. Deal-breakers table with PASS/FAIL/UNKNOWN.
5. One ASK: go / no-go / hold, owner, date.
6. Binding vs non-binding bits named or HOLE.
7. Not a term-sheet waterfall, not an NPV, not a kill card, not an RFP bid.
8. One page; "not legal advice" on page.

If 1, 3, 4, or 5 fail: do not ship.

## Escalate / stop

- They want clause drafting / SPA language → counsel; stop at screen.
- They want full synergy model before any screen → [Business Case](../../strategy/business-case/SKILL.md) after go, not instead.
- Regulatory FAIL already known → no-go or counsel path; do not "hope into DD".
- No themes and they still want go → refuse; blueprint missing.
