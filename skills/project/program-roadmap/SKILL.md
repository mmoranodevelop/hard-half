# Program Roadmap

**Program waves this quarter + one ASK** — tranches on a timeline, capacity against them, decisions due now. Outcome increments, not a stapled Gantt. Default: venture / transformation program; same spine for F500.

Method origin: MSP tranche / progressive delivery (waves that deliver a capability step-change + end-of-tranche review) + APM programme management (benefits-led, iterative next-step decisions) + PMI Standard for Program Management (align components; manage interdependencies at program level — high-level). Reconstruct the operator board. Do not invent dates or FTEs.

If they want an MSP / PI / Gantt lecture: one paragraph then produce or stop.

## When to use

- "What ships this quarter across the program?" / "Which tranche are we in?"
- SteerCo needs waves, capacity, and decisions — not a status tour
- Multiple projects must be sequenced into capability increments
- Near-term tranche is vague; later work is still being dated as if committed

## When not to use

- Authorise the program (outcome, in/out, D, 90 days) — [Program Charter](../../management/program-charter/SKILL.md)
- Go / Kill / Hold / Recycle one bet — [Portfolio Stage-Gate](../../management/portfolio-stage-gate/SKILL.md)
- Objectives and key results from strategy — [OKR Cascade](../../strategy/okr-cascade/SKILL.md)
- Post-close joint 2Q product roadmap for a customer — [Joint Roadmap Q1](../../ma/joint-roadmap-q1/SKILL.md)
- First 100 days outcomes after close / vendor go-live — [Integration 100](../../management/integration-100/SKILL.md)
- Cross-project dependency matrix — [Interdependency Map](../../project/interdependency-map/SKILL.md)
- Single-project plan — stop; not this skill

## Modes

| Mode | When | Output |
|---|---|---|
| **produce** | Default. Program named; tranche candidates exist | One-pager + this-quarter wave table + one ASK |
| **redline** | They pasted a mega-Gantt or "roadmap" of task names | Rebuild as outcome tranches; kill invented far dates |
| **refuse** | No program outcome, or they want a 3-year date novel | Issues list. Stop |

## Hard rules

1. **Tranches are capability increments**, not "Phase 1 Design / Phase 2 Build." End of a tranche = something the org can do that it could not, plus a review decision.
2. **Near-term committed; later coarse.** This quarter (or current + next tranche) gets dates. Beyond that: Next / Later — no fake precision.
3. **Capacity is named or HOLE.** People / teams / budget envelopes against the current tranche — do not invent FTEs or €.
4. **Decisions this sitting** are explicit (continue / reshape / kill next tranche; unlock capacity; accept slip). A roadmap with no decision is a poster.
5. **One ASK** — named D / sponsor to approve the current-tranche commit (or stop/resequence) by date.
6. **Never invent** dates, benefits $, or headcount. Holes stay holes.
7. **One page** (+ optional tranche table annex).

## Intake

If **two** of 1–3 are missing after one round: issues list, not a fake roadmap.

1. Program name, outcome sentence, named D / sponsor — load-bearing
2. Current and next proposed tranches (capability each delivers) — load-bearing
3. Capacity available to the current tranche (teams / named leads / envelope) — load-bearing or HOLE
4. Dependencies that gate the next tranche (names, not vibes)
5. Decisions due this quarter / this SteerCo
6. As-of date and quarter boundaries the org actually uses

## QA (must pass)

1. Tranches named as capabilities, not design/build phases.
2. Near-term dates; later coarse (Next/Later) — no invented far calendar.
3. Capacity stated with source or HOLE.
4. At least one decision this sitting.
5. One ASK with owner, verb, date.
6. Not charter, gate, OKR, joint M&A roadmap, or integration-100.
7. No invented FTEs, benefits $, or dates.
8. One page (+ optional annex).

If 1, 5, or 7 fail: do not ship.

## Escalate / stop

- No signed outcome / D → refuse; route to [Program Charter](../../management/program-charter/SKILL.md).
- They want Go/Kill of the whole bet → [Portfolio Stage-Gate](../../management/portfolio-stage-gate/SKILL.md).
- Capacity hole is cash → note; [Cash Runway](../../management/cash-runway/SKILL.md) owns liquidity.
- Cross-project blocks dominate → produce roadmap then hand matrix to [Interdependency Map](../../project/interdependency-map/SKILL.md).
