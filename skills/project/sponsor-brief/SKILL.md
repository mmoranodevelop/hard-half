# Sponsor Brief

**15-minute LIVE 1:1 with the PROJECT sponsor** — agenda spine, 3 facts, 1 decision, landmines, close ASK. Oral, manage-by-exception. Default: client project sponsor; same spine for internal exec sponsor of a named delivery.

Method origin: executive briefing craft (BLUF / Context–Headline–Ask) + PRINCE2-style manage-by-exception (escalate when forecast breaks tolerance; otherwise concise highlight) — live conversation, not a letter.

If they want a briefing / MbE lecture: one paragraph then produce or stop.

## When to use

- Calendar hold with the project sponsor (≈15 min) and you need the spine
- One decision must land live; email will not clear it
- Landmines (politics, bad news) must be pre-briefed, not sprung in a room
- Written status exists; the live ask is still open

## When not to use

- Written client highlight this period — [Sponsor Status](../../project/sponsor-status/SKILL.md)
- Seller-side exec on a live pursuit — [Exec Sponsor Live](../../commercial/exec-sponsor-live/SKILL.md)
- SteerCo sitting (up to 3 decisions, room) — [Steering Pack](../../project/steering-pack/SKILL.md)
- 1:1 with a direct report / workstream lead — [One-on-One](../../management/one-on-one/SKILL.md)
- Staffer written brief to a principal — [Principal Brief](../../writing/principal-brief/SKILL.md)
- Internal ops exceptions of our shop — [Operating Review](../../management/operating-review/SKILL.md)

## Modes

| Mode | When | Output |
|---|---|---|
| **produce** | Default. Named sponsor + meeting slot | 15-min live spine + ASK |
| **redline** | They pasted a status deck for "the chat" | Force 3 facts / 1 decision / landmines; kill tour |
| **refuse** | No sponsor named, or they want the written letter, or SteerCo pack | Issues list. Stop |

## Hard rules

1. **LIVE 1:1 with the PROJECT sponsor.** Not a room, not a seller pursuit, not a letter.
2. **Timebox spine:** ~2 min frame, ~6 min facts, ~5 min decision, ~2 min landmines/close.
3. **Exactly 3 facts** (exception-led). Colour without because fails.
4. **Exactly 1 decision** (or explicit "no decision — awareness only" with why).
5. **Landmines named** (what must not surprise them). No ambush.
6. **Close ASK** with owner (usually sponsor or you) + date.
7. **Do not invent burn, NPS, or % complete.** Hole them.
8. **Not sponsor-status letter, not exec-sponsor-live, not steering-pack, not principal-brief.**
9. **One page.**

## Intake

If **two** of 1–3 are missing after one round: issues list, not a fake script.

1. Named project + named sponsor + slot length — load-bearing
2. The one decision (or "awareness only") — load-bearing
3. Three facts with evidence dates — load-bearing
4. Landmines / bad news that must land first
5. What "done" looks like when you walk out
6. As-of of the numbers

## Output shape

```
SPONSOR BRIEF (LIVE)  |  [PROJECT]  |  Sponsor: [name]  |  slot: 15m  |  as-of: [date]
ASK: [sponsor / you] to [decide / unlock / escalate / hold] by [date]

AGENDA SPINE
0–2m  Frame: [why this slot] + tolerance check (inside / outside)
2–8m  Three facts (exception-led)
8–13m Decision: [the one call]  Options: A / B  Rec: [ ]
13–15m Landmines + close ASK

THREE FACTS
| # | Fact (≤12 words) | Because / evidence date | If ignored |

DECISION
Decision needed: [ ]    Rec: [ ]    If no decision today: [consequence]

LANDMINES
| Topic | Why it bites | Say first? |

WALK-OUT DONE
Looks like: [ ]

NOT THIS PAGE
Written letter → sponsor-status    Seller pursuit → exec-sponsor-live    SteerCo room → steering-pack    Staffer memo → principal-brief

Holes: [ ]
```

## QA (must pass)

1. Named project, sponsor, 15m (or stated slot).
2. Exactly 3 facts with evidence dates (or holes).
3. Exactly 1 decision or explicit awareness-only.
4. Landmines listed (or "none — say so").
5. Close ASK, owner, date.
6. No invented metrics.
7. Not letter / pursuit / SteerCo / principal-brief / report 1:1.
8. One page.

If 1, 3, 5, or 6 fail: do not ship.

## Escalate / stop

- Written client one-pager is the job → [Sponsor Status](../../project/sponsor-status/SKILL.md).
- Room with multiple decisions → [Steering Pack](../../project/steering-pack/SKILL.md).
- Seller pursuit exec → [Exec Sponsor Live](../../commercial/exec-sponsor-live/SKILL.md).
- No sponsor name after one ask → refuse.
- Forecast outside tolerance and they want to hide it → refuse; put exception on page 1.
