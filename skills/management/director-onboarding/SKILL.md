# Director Onboarding

**New director 30-day kit — one page** — materials list, 1:1 map, first-board prep, conflicts / independence, pack owner. Default: private-company / PE-backed board; same spine for public (add listing / insider rules as holes for counsel).

Method origin: NACD new-director onboarding / first-year handbook public; Spencer Stuart new-director onboarding recommendations (structured program, 1:1s, mentor, materials before first sitting).

If they want a governance career lecture: one paragraph then produce or stop.

## When to use

- New director accepted; first sitting inside ~30–45 days
- CorpSec / NomGov asks for an onboarding checklist that is not HR
- Materials and 1:1s are ad hoc; conflicts undeclared
- Chair wants a mentor + first-board brief named

## When not to use

- Employee / exec 90-day plan — [Ninety Day Onboarding](../../learning/ninety-day-onboarding/SKILL.md)
- Day-1 employee pack post-deal — [Day1 Employee Pack](../../ma/day1-employee-pack/SKILL.md)
- Annual board rhythm / consent calendar — [Board Calendar](../../management/board-calendar/SKILL.md)
- The decision paper for a sitting — [Executive Board Memo](../../management/executive-board-memo/SKILL.md)
- Spoken delivery / hostile Q — [Board Spoken](../../comms/board-spoken/SKILL.md) / [Board Q&A Prep](../../writing/board-qa-prep/SKILL.md)
- Leadership Day-1 post-close (mgmt) — [Leadership Day1](../../ma/leadership-day1/SKILL.md)

Fiduciary director kit ≠ employee onboarding.

## Modes

| Mode | When | Output |
|---|---|---|
| **produce** | Default. Named director + first sitting date | 30-day kit one-pager + one ASK |
| **redline** | They pasted an HR orientation or binder dump | Strip to materials / 1:1s / first board / conflicts |
| **refuse** | No director name, no first sitting window, or "make them an employee plan" | Issues list. Stop |

## Hard rules

1. **Named director. First sitting date (or window).** Day 0 = acceptance / appointment.
2. **Materials before first sitting** — governance docs, strategy, financials, risk, bios, last packs. Portal link or hole.
3. **1:1 map:** chair / lead, CEO, CFO, GC/CorpSec, committee chairs relevant, mentor director. Each with owner to schedule.
4. **Conflicts / independence / trading policy** flagged for counsel — do not invent legal clearance.
5. **First-board brief:** purpose of that sitting, consent vs discuss, how to pull from consent, who debriefs after.
6. **One ASK** — send portal / schedule 1:1s / assign mentor / clear conflicts questionnaire. Owner, date.
7. **Not an employee 30-60-90.** No payroll, no manager scorecard.
8. **Do not invent D&O insurance limits or listing rules.** Hole for GC.
9. **Ongoing beyond day 30 is a pointer**, not a second novel on this page.
10. **One page.**

## Intake

If **two** of 1–3 are missing after one round: issues list, not a fake kit.

1. Director name, role (independent / investor / exec), start — load-bearing
2. First board date / window — load-bearing
3. Pack owner (CorpSec / GC) — load-bearing
4. Committee assignment (known / TBD)
5. Mentor candidate
6. Known conflict flags
7. The ASK (send / schedule / clear)

## QA (must pass)

1. Named director and first sitting window.
2. Materials list with owners/dates (or holes).
3. 1:1 map includes chair/CEO/CorpSec at minimum.
4. Conflicts path named; no invented legal clearance.
5. First-board brief present.
6. One ASK with owner, date.
7. Not an employee onboarding plan.
8. One page.

If 1, 4, 6, or 7 fail: do not ship.

## Escalate / stop

- They want employee / exec 90-day → [Ninety Day Onboarding](../../learning/ninety-day-onboarding/SKILL.md).
- Conflict or insider-trading question → GC / counsel; kit is exhibit only.
- No first sitting date after one ask → refuse.
- Public-company listing onboarding extras unknown → hole; do not invent.
- Annual calendar still missing → [Board Calendar](../../management/board-calendar/SKILL.md).
