# Integration 100

**First-100-days one-pager** after a **close** or a **vendor go-live**: 5–7 outcomes, named owners, the date the old path dies. Default: venture; same spine for F500. Two skins, one artifact.

Public method. McKinsey public: most deal value is integration execution; protect the base, sequence disruption. Bain public (IT in M&A): decide the platform in the first months; "best of breed" delay is how you run two of everything forever. TSA / dual-run craft: old path has an **exit date and a test**, not a vibe. Hypercare has **exit criteria**, not a calendar hope. Do not dump a PMI manual. Do not invent a firm's IMO kit.

If they want Kotter 8, one paragraph then produce or stop.

## When to use

- Day 0 is a **close** (acquisition, carve-out, merger of ops)
- Day 0 is a **major vendor / system go-live** and two paths will otherwise run forever
- "We went live / we closed — now what" with no owners
- Dual-running, TSA, or the legacy tool has no kill date

## When not to use

- Getting people to **do the new behaviour** — [Change Adoption](../../management/change-adoption/SKILL.md)
- Onboarding a **person** — [Ninety-Day Onboarding](../../learning/ninety-day-onboarding/SKILL.md)
- Authorising the program — [Program Charter](../../management/program-charter/SKILL.md)
- The vendor paper — [Vendor SOW](../../management/vendor-sow/SKILL.md)
- Weekly exceptions after Day 100 is BAU — [Operating Review](../../management/operating-review/SKILL.md)

## Modes

| Mode | When | Output |
|---|---|---|
| **produce** | Default. Close or go-live is dated (or this week) | 100-day one-pager |
| **redline** | They pasted a 40-slide "Day 1 pack" | Kill activity lists; force outcomes + kill-old-path |
| **refuse** | No Day 0, no outcomes, and they want a PMI lecture | Issues list. Stop |

Skin: **close** | **go-live**. If unclear, ask once; default go-live for a vendor, close for a deal.

## Hard rules

1. **Outcomes, not workstreams.** "Stand up IMO" is not an outcome. "Payroll runs on the buyer calendar with zero missed pays by Day 30" is.
2. **Every outcome has one owner (a name) and a date inside 100 days.** A committee is not an owner.
3. **Kill the old path is mandatory.** Name the legacy system, process, vendor, or dual-run. Kill test (what must be true). Kill date. Who turns it off. "We'll run both until people are comfortable" is a fail.
4. **Day 1 is continuity, not synergy theatre.** Customers, payroll, access, cash application, support. McKinsey public: do not smash the sales force and the CRM on the same week if the thesis is revenue.
5. **Hypercare has exit criteria.** Incident threshold, named BAU owner, knowledge transfer done. A date without a test is not exit.
6. **TSA / dual-run:** each line has a landing zone, a dual-run test, a "no later than" exit. Burn without an exit is a hole.
7. **Do not duplicate change-adoption.** You may *point* at behaviours; this page owns systems, owners, and the kill.
8. **Do not invent synergy numbers or go-live metrics.** Holes stay holes.

## Intake

If **Day 0 date** and **what must be true by Day 100** are both missing after one round: issues list.

1. Skin: close or vendor go-live. Day 0 date (or "T-minus / T-plus")
2. What must be true by Day 100 (their words)
3. What must not break on Day 1
4. Old path that will otherwise live (system, vendor, process)
5. Owners you already have (IMO / program / BAU)
6. TSA / dual-run / hypercare already in a contract?
7. Venture or F500 (venture default)

## QA (must pass)

1. Skin and Day 0 named.
2. 5–7 testable outcomes, each with a name and a date ≤ Day 100.
3. At least one kill-old-path row with a test and a date (or a labelled hole).
4. Day 1 "must not break" is not empty.
5. Hypercare exit is a test, not only a date.
6. ASK + owner + date.
7. Not an ADKAR/Kotter essay.
8. Not a person's 30-60-90.
9. No invented synergy or SLA numbers.
10. One page.

If 2, 3, or 6 fail: do not ship.

## Escalate / stop

- They want "best of breed, decide later" as the plan → fail kill-old-path; do not ship a dual-run with no date.
- They want you to write the change-adoption behaviours as this page → route.
- They want a 200-line PMI playbook → refuse; this is the 100-day contract.
- Works-council, TUPE, data residency, step-in → counsel, still name the outcome as a hole.
- Day 0 was 80 days ago and nothing is owned → still produce; mark days spent; do not backdate fiction.
