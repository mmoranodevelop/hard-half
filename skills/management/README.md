# management

Exec, board, people, and the operating system of a shop.

## Model-invoked

Reachable by you *or* selected automatically by the agent when a task matches.

- [`after-action-review`](after-action-review/SKILL.md) — Use when a completed or mid-run event needs a short no-blame learning record: what was supposed to happen, what did, why, and 2–5 actions with owner, date, next event.
- [`ai-ops-policy`](ai-ops-policy/SKILL.md) — Use when an exec needs an allowed / banned / human-review AI use policy by workflow, plus data rules and one ASK to approve.
- [`board-calendar`](board-calendar/SKILL.md) — Use when setting the annual board rhythm: meeting dates, consent vs discuss, pack owner, pack-send dead zones.
- [`budget-variance`](budget-variance/SKILL.md) — Use when an MD must explain this period vs last vs plan with three drivers and one reallocation ASK.
- [`cash-runway`](cash-runway/SKILL.md) — Use when an MD (default: ventures) must see near-term cash: 13-week strip plus one-page ask — receipts, disbursements, net burn, runway, collections, payables.
- [`change-adoption`](change-adoption/SKILL.md) — Use when a program is shipping a change and people must do the new behaviour: one-pager with owners, ADKAR barrier by role, leading indicators, one ASK.
- [`comp-band-decision`](comp-band-decision/SKILL.md) — Use for one hire/promo: band, market, exception, fairness check, approve/deny ASK.
- [`cyber-incident-brief`](cyber-incident-brief/SKILL.md) — Use for a CEO/board one-pager in the first 24–72h of a cyber incident: facts known/unknown, customer/regulator, containment, one ASK.
- [`data-residency`](data-residency/SKILL.md) — Use when customer data location must be checked against contracts: gap map, remediation, one ASK.
- [`decision-meeting`](decision-meeting/SKILL.md) — Use when one named decision must be taken in a room this week: invite with a named D, narrative pre-read, same-day decision record.
- [`decision-rights`](decision-rights/SKILL.md) — Use when a named decision is stuck: one-page RAPID map with one D.
- [`director-onboarding`](director-onboarding/SKILL.md) — Use when building a new board director 30-day kit: materials, 1:1s, first board, conflicts.
- [`executive-board-memo`](executive-board-memo/SKILL.md) — Write a decision-grade memo a CEO, ELT, or board uses to decide — for-decision, for-discussion, or for-noting papers and one-pagers a principal can sign.
- [`headcount-plan`](headcount-plan/SKILL.md) — Use when an MD must lock roles, start dates, fully-loaded cost, and freeze vs hire for the next 12–18 months.
- [`hiring-scorecard`](hiring-scorecard/SKILL.md) — Use when opening a role before sourcing: mission, 12-month outcomes, must vs nice, walk-aways, named D.
- [`incentive-plan`](incentive-plan/SKILL.md) — Use for one bonus or equity cycle: metrics, weights, gates, unintended gaming, approve ASK.
- [`integration-100`](integration-100/SKILL.md) — Use for the first 100 days after a close or a major vendor go-live: outcomes, owners, kill-the-old-path dates.
- [`litigation-reserve`](litigation-reserve/SKILL.md) — Use when a material dispute needs exposure, reserve range, settlement band, counsel status, and one ASK.
- [`one-on-one`](one-on-one/SKILL.md) — Use when running this week's 1:1 with a direct report (MD) or workstream lead (program manager): their agenda, one challenge, actions with dates.
- [`operating-review`](operating-review/SKILL.md) — Use when an MD or program manager needs this period's exception pack: one-page score, red/yellow with owner and date, one ASK.
- [`org-one-pager`](org-one-pager/SKILL.md) — Use when drawing who reports where for a named team of N: boxes, spans, layers, vacancies, one solid line.
- [`portfolio-stage-gate`](portfolio-stage-gate/SKILL.md) — Use when an MD must Go / Kill / Hold / Recycle one internal bet: one-page gate paper with evidence bar, kill criteria, named resources, one ASK.
- [`pre-mortem`](pre-mortem/SKILL.md) — Use when a plan is about to launch and the room is too invested to dissent: imagine it already failed, harvest why, change the plan.
- [`program-charter`](program-charter/SKILL.md) — Use when writing the one-page authorisation for a program: outcome, in/out of scope, benefits, constraints, D, success tests, first 90 days.
- [`qbr`](qbr/SKILL.md) — Use when running a quarterly review with one named customer or one named sponsor: outcomes scorecard, risks, next-quarter ask.
- [`raid-register`](raid-register/SKILL.md) — Use when building an MD-readable RAID (Risks, Assumptions, Issues, Dependencies): owner, date, trigger, residual, one ASK.
- [`skip-level`](skip-level/SKILL.md) — Use when preparing one skip-level conversation: purpose, questions, what you will not do with it.
- [`span-of-control`](span-of-control/SKILL.md) — Use when deciding managerial density / layers vs throughput this quarter — rightsize spans by work type, flag over/under-management, one ASK.
- [`stakeholder-alignment`](stakeholder-alignment/SKILL.md) — Use when a program, decision, or change will stall unless named people believe and act: map plus belief gaps plus conversation plan with one ASK each.
- [`succession-slate`](succession-slate/SKILL.md) — Use for critical-role succession: ready-now / ready-1-2y / emergency cover.
- [`vendor-scorecard`](vendor-scorecard/SKILL.md) — Use when scoring whether a named vendor is passing the SOW tests this month: quality, schedule, cost, management, credits, continue/cure/exit.
- [`vendor-sow`](vendor-sow/SKILL.md) — Use when a program manager is buying an agency, integrator, or software implementation and needs a statement of work: outcome, acceptance tests, price-to-scope, IP choice, exit, one ASK.
