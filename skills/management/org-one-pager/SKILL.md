# Org One-Pager

**Org one-pager for a team of N** — boxes, spans, who reports where, vacancies marked, one ASK (approve this chart / hire / flatten / split). Default: venture team; same spine for an F500 function.

Method origin: Galbraith Star Model (public) — shape is span of control at each level; this page draws the hardware. Bain public spans-and-layers: no magic number; count the baseline before you preach. Fayol public: one solid line (unity of command).

If they want a lecture on org design: one paragraph then produce or stop.

## When to use

- "Draw the team" / reorg a squad of N / "who do these people report to"
- Span is 1 (assistant-with-a-title) or everyone reports to the founder
- Vacancies, contractors, and dual reports are invisible in the current chart
- Before a hiring wave so the new boxes have a manager

## When not to use

- Who has the D on a named decision — [Decision Rights](../../management/decision-rights/SKILL.md)
- Opening a role, interview loop, debrief — [Hiring Scorecard](../../management/hiring-scorecard/SKILL.md)
- First 90 days of a person — [Ninety-Day Onboarding](../../learning/ninety-day-onboarding/SKILL.md)
- Roles, start dates, fully-loaded cost, freeze vs hire — [Headcount Plan](../../management/headcount-plan/SKILL.md)
- Conversation two layers down — [Skip-Level](../../management/skip-level/SKILL.md)
- Authorises the work, not the org — [Program Charter](../../management/program-charter/SKILL.md)
- Post-deal hold/absorb/merge per function — [Operating Model Choice](../../ma/operating-model-choice/SKILL.md)
- A 40-box enterprise operating-model redesign (offer this page for the slice they will actually change)

## Modes

| Mode | When | Output |
|---|---|---|
| **produce** | Default. Names + N exist or can be listed | One-pager chart + span table + ASK |
| **redline** | They pasted a chart or a slide | Fail unity-of-command, span, vacancy, N; redraw |
| **refuse** | No names, no N, and they want "a typical startup org" | Issues list. Stop |

## Hard rules

1. **N must add up.** Every named human (FTE, contractor, vacant box you intend to fill) is in exactly one home box. If the count does not match the headcount they gave, stop and show the gap.
2. **One solid line.** Each person has one manager of record. A second boss is a dotted line with a purpose. Hidden dual reporting is a fail.
3. **Span is a number on the page.** For each manager: count of solid-line directs. Flag: span=1 (layer for status), span that does not match work type, manager with no time to 1:1.
4. **Vacancies are boxes, not vibes.** "We'll hire a head of X" is a vacant box with a date or a hole.
5. **Contractors and vendors are marked**, not drawn as if they were employees.
6. **Layers from the named top to the front line**, counted. A skip-level on the chart is either a design or an error — say which.
7. **This is not RAPID.** Reporting line ≠ decision right.
8. **Do not invent people, titles, or reporting lines.** Holes stay holes.

## Intake

If **N** and **who the top box is** are both missing after one round: issues list.

1. Team name, top box (name + role), N (or a list)
2. Names / roles you have, including vacancies and contractors
3. Known dual / matrix reports
4. What is changing (reorg, hire, founder span, post-close)
5. Constraint (cannot fire, location, union, "keep titles")
6. ASK (approve chart / open roles / flatten / split)
7. Venture or F500 (venture default)

## Output shape

```
ORG ONE-PAGER  |  [team]  |  [date]  |  N = [ ]
Top box: [name, role]     Layers (top → front): [ ]

ASK: approve this chart | open [roles] | flatten [layer] | split [span]
Owner: [ ]    Decide-by: [ ]

BOXES (solid line)
[Top]
  ├ [Name] — [role] — span [n] — directs: [names]
  │    └ [Name] — [role]
  ├ [VACANT] — [role] — fill-by [date or hole]
  └ [Contractor: Name] — [role] — vendor [ ] — ends [ ]

SPAN TABLE
| Manager | Work type (skills / task) | Span | Directs | Flag |
| [ ] | [ ] | [ ] | [ ] | 1 / wide / ok |

DOTTED (purpose, not a second solid line)
| Person | Dotted to | Purpose | Who still does 1:1 |
| [ ] | [ ] | [ ] | [ ] |

- [name — reports to …]

HOLES
- [unnamed people in the N; unknown managers]

```

## QA (must pass)

1. N stated; arithmetic matches or the gap is labelled.
2. One solid line per person.
3. Every manager has a span number.
4. Vacancies are boxes with a date or a hole.
5. Contractors marked.
6. Dotted lines have a purpose.
7. ASK + owner + date.
8. Not a RAPID map.
9. No invented names.
10. Fits on one page (or one page + a named overflow list).

If 1, 2, or 7 fail: do not ship.

## Escalate / stop

- They want a "typical" org with no names → refuse. Offer a blank template, not fiction.
- They want to hide a dual report "to keep politics calm" → draw both lines; say so.
- Legal / works-council / TUPE / discrimination in who is drawn out → HR/counsel.
- They actually need who decides, not who reports — [Decision Rights](../../management/decision-rights/SKILL.md).
- They actually need to open a role — [Hiring Scorecard](../../management/hiring-scorecard/SKILL.md), using this chart as input.
