# Incentive Plan

**One-cycle incentive design pack** — eligible population, metrics + weights, gates/hurdles, payout curve shape, gaming risks, one ASK (approve / revise / kill a metric). Covers STI/bonus and PE-style MIP/equity cycle. Default: venture leadership cycle; same spine for F500 AIP or PortCo MIP.

Method origin: WorldatWork public incentive-pay practice — AIP metrics, thresholds, eligibility; PE PortCo LTI/MIP concepts (pool, vesting, hurdles). Harvard/Kerr public — folly of rewarding A while hoping for B; design against gaming. Public PE MIP vs LTIP contrast (exit-linked vs time/performance).

If they want a comp-philosophy lecture: one paragraph then produce or stop.

## When to use

- Design or refresh one bonus / AIP / equity / MIP cycle before it launches
- "What do we pay for?" needs metrics, weights, and gates on one page
- Suspected gaming (sandbag, discount-to-close, expansion-over-retention)
- Board / CompCom / PE sponsor must approve the cycle rules
- Split of STI vs equity unclear for the named population

## When not to use

- Cascading goals / KR owners — [OKR Cascade](../../strategy/okr-cascade/SKILL.md)
- One person's band / level / offer cash — [Comp Band Decision](../../management/comp-band-decision/SKILL.md)
- Roles, dates, fully-loaded cost — [Headcount Plan](../../management/headcount-plan/SKILL.md)
- Sales discount exception on one deal — [Discount Exception](../../strategy/discount-exception/SKILL.md)
- Org boxes / spans — [Org One-Pager](../../management/org-one-pager/SKILL.md) / [Span of Control](../../management/span-of-control/SKILL.md)
- Multi-year workforce philosophy essay (not a cycle)

## Modes

| Mode | When | Output |
|---|---|---|
| **produce** | Default. Population + cycle window known | Metrics/weights/gates + gaming + ASK |
| **redline** | They pasted a plan or a "pay for growth" slide | Force weights, gates, gaming; kill single-metric plans |
| **refuse** | No population, no cycle dates, and they want "market STI %" | Issues list. Stop |

## Hard rules

1. **One cycle, one page.** Name the performance window and payout / vesting window. Multi-year philosophy is out of scope.
2. **Metrics ≤ few, each weighted.** WorldatWork-style AIP: name each measure, weight, threshold / target / stretch if known. Do not invent market %.
3. **Gates before upside.** Company or team gate (profitability, cash, safety, compliance) stated or HOLE. No gate = labelled risk.
4. **Gaming column required.** For each metric: how a rational actor games it (Kerr). If you cannot name the game, the metric is not ready.
5. **STI ≠ equity ≠ MIP.** Bonus cycle ≠ equity pool ≠ PE exit MIP. Say which instrument this page is. Do not blend silently.
6. **Eligibility is a list or a rule.** Roles / levels in; contractors in or out; new hires proration — or HOLE.
7. **Do not invent payout tables, pool %, or MOIC hurdles.** Holes stay holes. Cite method, not fake benchmarks.
8. **One ASK.** Approve this cycle / drop metric X / add gate Y — not "align incentives."

## Intake

If **population** and **cycle window** are both missing after one round: issues list.

1. Instrument (STI / bonus / equity grant cycle / PE MIP)
2. Eligible population (roles or named list)
3. Performance period + payout / vest / exit trigger
4. Candidate metrics (or "blank — design")
5. Known gates (company / team / individual)
6. Known gaming history or "none observed"
7. Approver (CEO / CompCom / PE sponsor) + decide-by date

## QA (must pass)

1. Instrument and cycle window named.
2. Population named or rule stated.
3. Each metric has weight (or HOLE) and a gaming line.
4. Gates present or labelled HOLE/risk.
5. One ASK + owner + date.
6. Not OKRs, not a band decision, not a headcount plan.
7. No invented market STI %, pool %, or MOIC numbers.
8. One page.

If 1, 3, 5, or 7 fail: do not ship.

## Escalate / stop

- They want "what do peers pay?" with no population → refuse; method not a survey dump.
- Legal / tax / securities / 409A / EMI issues → counsel / CompCom.
- They actually need goal cascade — [OKR Cascade](../../strategy/okr-cascade/SKILL.md).
- They actually need one person's cash band — [Comp Band Decision](../../management/comp-band-decision/SKILL.md).
- Plan rewards A while leadership hopes for B and refuses to change metrics → escalate to approver with gaming column visible.
