# IMO Charter

**One-page IMO charter** the sponsor can sign — thesis, named D, Integration Leader, Value Creation Lead, what the IMO will not run, Day 1 locked vs deferred, success tests, first 90 days. Default: venture deal; F500: name steering members and decision rights (org, spend, customer, systems).

Method origin: McKinsey public next-generation IMO (Integration Leader + Value Lead + CEO-led steering) versus a traffic-cop PMO.

If they want an IMO vs PMO / PMI lecture: one paragraph then produce or stop.

## When to use

- Deal is signed or close is dated and there is no value vehicle, only a PMO
- The "IMO" is a RACI with no thesis and no Value Lead
- Steering exists; nobody has the D to start / redirect / kill
- Day 1 locked vs deferred is still a vibe

## When not to use

- Generic program authorisation — [Program Charter](../../management/program-charter/SKILL.md)
- Weekly sitting and pack — [Steering Pack](../../project/steering-pack/SKILL.md)
- Living risks / issues — [RAID Register](../../management/raid-register/SKILL.md)
- Task RACI wallpaper — [RACI Delivery](../../project/raci-delivery/SKILL.md)
- First 100-day outcomes + kill-old-path — [Integration 100](../../management/integration-100/SKILL.md)
- Hold / absorb / merge / harvest per function — [Operating Model Choice](../../ma/operating-model-choice/SKILL.md)
- Who runs the combined unit Day 1 — [Day-1 Leadership Slate](../../ma/leadership-day1/SKILL.md)
- Stay / walk-away names — [Key Talent Slate](../../ma/key-talent-slate/SKILL.md)

## Modes

| Mode | When | Output |
|---|---|---|
| **produce** | Default. Named deal | One-page IMO charter + ASK |
| **redline** | They pasted a PID / PMO RACI labelled IMO | Extract thesis, D, IL, Value Lead; cut the binder |
| **refuse** | Two load-bearing facts missing, or a PMI lecture | Issues list. Stop |

## Hard rules

1. Thesis in one sentence. A workstream list is not a thesis.
2. One D. Integration Leader recommends and performs; does not silently hold D.
3. Value Lead is mandatory. No value owner = it is a PMO — refuse that costume.
4. Workstreams: named leads. Write **not this IMO**. BAU stays in the line.
5. Fence Day 1 locked vs end-state deferred. Point at [Operating Model Choice](../../ma/operating-model-choice/SKILL.md); do not design the OM here.
6. Success tests: synergy run-rate, base-business growth, TSA exit, customer continuity. Holes stay holes. Kill test before happy tests.
7. First 90 days + next gate + envelope. Sign lines: D, IL, Value Lead.
8. **Do not invent synergy amounts or FTE counts.**

## Intake

If **two** of 1, 2, 3 are missing after one round: issues list, not a fake charter.

1. Integration thesis — how this integration delivers the deal (not a workstream list) — load-bearing
2. D — who starts / redirects / kills (usually CEO / deal sponsor) — load-bearing
3. Integration Leader — named; full-time? — load-bearing
4. Value Creation Lead — named; owns baseline, tracker, finance recon
5. What the IMO will not run — BAU stays in the line
6. Day 1 locked vs deferred
7. Success tests + first 90 days / next gate

## QA (must pass)

1. ASK (D, authorise, date, envelope or FTEs).
2. Thesis is not a workstream list.
3. Named D.
4. Integration Leader named and Value Lead named.
5. "Not this IMO" written.
6. Day 1 vs end-state fence.
7. Success test and 90-day date present.
8. Not a program-charter, steering-pack, or 40-page PID in costume. No invented synergy $. One page.

If 1, 2, 3, or 4 fail: do not ship.

## Escalate / stop

- Two of thesis / D / Integration Leader missing after one ask → issues list.
- PMO RACI with no Value Lead → refuse; it is not an IMO.
- Steering with no named D → refuse.
- They insist on 40 pages → extract this page or stop.
- They want the OM designed here → [Operating Model Choice](../../ma/operating-model-choice/SKILL.md).
- They want 100-day outcomes → [Integration 100](../../management/integration-100/SKILL.md).
