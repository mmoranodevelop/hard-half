# Renewal Risk

**Named Renewal — Save / Reshape / Walk** — one page inside two quarters: why it might miss, multi-thread, commercial $, ASK this month. Default: professional-services / program book; same spine for SaaS CS.

Method origin: Gainsight-public renewal craft (start before the notice window; auto-renew is not a plan) + MEDDPICC public flags (economic buyer, champion, competition including do-nothing).

If they want a renewals lecture: one paragraph then produce or stop.

## When to use

- Named contract / SOW / subscription renews in ≤2 quarters
- Health is yellow/red, champion is thin, or a competitor is in the building
- "Will they renew?" needs a save-or-walk call this month

## When not to use

- One price yes/no vs list — [Discount Exception](../../strategy/discount-exception/SKILL.md)
- They are leaving this week / this month — [Churn Save](../../accounts/churn-save/SKILL.md)
- Quarterly sitting pack — [QBR](../../management/qbr/SKILL.md)
- This month's three flags with no renewal cliff — [Account Health](../../accounts/account-health/SKILL.md)
- Closed-lost after they chose out — [Win Loss](../../strategy/win-loss/SKILL.md)
- This week's Commit number — [Forecast Call](../../commercial/forecast-call/SKILL.md)
- Joint dated save plan once verdict is save — [Mutual Action Plan](../../accounts/mutual-action-plan/SKILL.md)

If they will not name the account and the date, stop.

## Modes

| Mode | When | Output |
|---|---|---|
| **produce** | Default | Save / reshape / walk page + ASK |
| **redline** | They pasted a renewal forecast note | Force buyer / multi-thread / walk option |
| **refuse** | Two load-bearing facts missing | Issues list. Stop |

## Hard rules

1. **Named account, instrument, date.** "Q4 renewals" is a list, not this page.
2. **Horizon ≤2 quarters.** Farther → [Account Plan](../../accounts/account-plan/SKILL.md) or [Account Health](../../accounts/account-health/SKILL.md). Already out → [Churn Save](../../accounts/churn-save/SKILL.md).
3. **Economic buyer named**, or the forecast is invalid. Champion ≠ buyer.
4. **Multi-thread count.** One contact is not green.
5. **Commercial on the page:** current $, asked $, notice / auto-renew. A silent discount routes to [Discount Exception](../../strategy/discount-exception/SKILL.md).
6. **Competition including do-nothing / in-house.** Hole if unknown — do not invent a rival.
7. **Verdict: save / reshape / walk.** "Hope they auto-renew" fails.
8. **Do not invent save-probability %.** RYG + because.

## Intake

If **account** and **renewal date** are both missing after one round: issues list.

1. Account, instrument, renewal date, notice / auto-renew — load-bearing
2. Current $ and what they have signalled (flat / down / out / unknown) — load-bearing
3. Economic buyer, champion, other threads
4. Why it might not land
5. What we will offer to save, or the walk terms
6. Our owner and the ASK this month

## QA (must pass)

1. Named account, instrument, renewal date ≤2Q.
2. Economic buyer named or forecast flagged invalid.
3. Multi-thread count; single-thread is not green.
4. Commercial $ current and asked; silent discount routed.
5. Competition / do-nothing named or holed — not invented.
6. Verdict save / reshape / walk. No "hope".
7. One ASK this month, owner, date.
8. Not a discount desk. Not a churn-save. One page.

If 1, 2, 6, or 7 fail: do not ship.

## Escalate / stop

- They already said they are out → [Churn Save](../../accounts/churn-save/SKILL.md).
- The only move is off-list price → [Discount Exception](../../strategy/discount-exception/SKILL.md); this page still holds save-or-walk.
- Deal already closed-lost → [Win Loss](../../strategy/win-loss/SKILL.md).
- Legal / procurement paper is the block — name it; a health call does not fix paper.
