# Expansion Whitespace

A **whitespace 1-pager for ONE named account**: the empty cells (job × offer × buying centre), which we will chase, **the next conversation**. Default: professional-services / program book. Same spine for agency or SaaS CS.

Public method: whitespace matrix public (offer × buying centre; empty cell = unsold adjacency); Challenger public — the conversation teaches a job, it does not tour the catalog. Reconstruct the operator card. Do not dump a land-and-expand sermon.

If they want "teach me whitespace / Challenger": one paragraph then produce or stop.

## When to use

- Named account: where else can we create value this year
- We are landed in one practice / SKU / geo and going blind elsewhere
- Need the next conversation, not a 12-month plan
- Rewrite a "cross-sell opportunities" slide into one cell + ASK

## When not to use

- Tear down a **named rival** — [Competitive Teardown](../../strategy/competitive-teardown/SKILL.md)
- Capital / NPV for a new bet — [Business Case](../../strategy/business-case/SKILL.md)
- 12-month plan for the account — [Account Plan](../../accounts/account-plan/SKILL.md) (this page may **feed** it)
- Joint dated plan they co-own — [Mutual Action Plan](../../accounts/mutual-action-plan/SKILL.md)
- Customer-back job with no named account — [Jobs to Be Done](../../strategy/jobs-to-be-done/SKILL.md)
- One price yes/no on a named add-on — [Discount Exception](../../strategy/discount-exception/SKILL.md)

If they will not name the account, stop.

## Modes

| Mode | When | Output |
|---|---|---|
| **produce** | Default | Whitespace 1-pager + next-conversation ASK |
| **redline** | They pasted a product-matrix or "upsell" slide | Same cells; force job + named conversation; kill the catalog |
| **refuse** | No account, or a lecture on land-and-expand | Issues list or one paragraph then stop |

## Hard rules

1. **One named account.** Not a segment slogan.
2. **Matrix is small.** Offers we actually sell × buying centres we can name. Empty cell = white. Occupied = landed. Do-not-chase is a third mark, not a dream.
3. **Job first, offer second.** "They don't have Product B" is not a job. Name the work they are trying to get done.
4. **Chase ≤3 cells this period.** Rank by: named buyer we can reach, job we can evidence, offer we can deliver. The rest is park.
5. **Next conversation is a person, a date, a teaching point.** Not "nurture the account".
6. **Do not invent budget or WTP.** Hole: `[budget unknown — ask by DATE]`.
7. **Health is a gate.** A red delivery/relationship account does not get a whitespace hunt until [Account Health](../../accounts/account-health/SKILL.md) or [Churn Save](../../accounts/churn-save/SKILL.md) says otherwise. Say so.
8. **Not a competitor teardown.** Incumbent in a cell = one word ("incumbent: [name or unknown]"), not a system map.
9. **SaaS CS skin:** SKU / module / seat expansion instead of practice lines. Spine stays.
10. **One page.**

## Intake

Refuse a FOR-SENDING page if the account *and* at least one empty cell we might chase are both missing. Two load-bearing holes → issues list. "We should cross-sell" with no cell is an issues list.

1. **Account**, landed offer(s), our owner
2. **Buying centres / geos / jobs** we can name (or "unknown — first task")
3. **Offers we actually sell** into this type of account
4. **Health colour** (red = stop hunt unless they override)
5. **Who we can reach** for the next conversation
6. **The ASK** (book the conversation / park / wait)

## Workflow

1. Landed vs empty vs park. Health gate.
2. Pick ≤3 cells: job, offer, buyer we can reach.
3. Next conversation + ASK.

## QA (must pass)

1. Named account, landed offer named.
2. Matrix with L/W/P, not a catalog dump.
3. ≤3 chase cells; each has a *job* not just an offer.
4. Next conversation is a person + date + teaching point.
5. Health gate: red waits unless override written.
6. One ASK, owner, date.
7. No invented budget / WTP.
8. Incumbent is a word, not a teardown.
9. Not a business case, not a 12-month account-plan as the whole job.
10. One page.

If 1, 3, 4, or 6 fail: do not ship.

## Escalate / stop

- Cell needs capital / a new offer we do not sell → [Business Case](../../strategy/business-case/SKILL.md) or stop.
- They want a rival system map → [Competitive Teardown](../../strategy/competitive-teardown/SKILL.md).
- Account is red/leaving → [Account Health](../../accounts/account-health/SKILL.md) / [Churn Save](../../accounts/churn-save/SKILL.md).
- Job is unnamed and they refuse to name a buying centre → issues list.
