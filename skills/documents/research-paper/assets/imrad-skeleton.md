## Abstract (write last; miniature of the paper; every number appears in the body)

**ICMJE structured (default biomedical):** context; purpose; procedures (participants, settings, measurements, analysis); main findings **with effect sizes and statistical/clinical significance**; principal conclusions; **important limitations**. No over-interpretation. Trials: registration number at end.

**Nature summary paragraph (~200 words, fully referenced, outsiders):** (i) 2–3 sentences basic introduction; (ii) background + rationale; (iii) main conclusions introduced by “Here we show”; (iv) 2–3 sentences general context.

Refuse: “novel / new / for the first time / unprecedented / extremely / outstanding / amazingly.”

## Introduction

Context. Specific objective or hypothesis. Cite only pertinent work. **No results or conclusions of this study** (ICMJE).

## Methods (protocol-time information only)

How and why the study was done that way. A stranger with the data could reproduce. **Everything obtained during the study belongs in Results.**

- Eligibility / exclusion; source population
- Primary and secondary outcomes (prespecified)
- Procedures and equipment sufficient to replicate
- Statistical methods; software + **version**; effect sizes + CIs, not *P* alone
- **Prespecified vs exploratory** (including subgroups) — labelled here **before** Results
- Ethics / IRB / Helsinki if human; consent
- Exact *n* plan
- Data and code availability path (or labelled restriction + another verification avenue)
- LLM use if any (Nature: document here; ICMJE: humans accountable; LLM **not** an author)
- Venue extras: Cell STAR headings + Key Resources Table; Nature reporting summary; CONSORT 2025 for trials; registration ID (WHO ICTRP / ClinicalTrials.gov) at or before first consent

Nature: Methods typically ≤ 3,000 words; may be longer; no figures/tables in Methods. If Methods exist, **legends MUST NOT contain methods**.

Logical sequence. Exact *n* used to calculate statistics (individual values, not a range if *n* varied). Define error bars (SD vs SEM). Exact *P* where relevant; F / t / df for ANOVA / t-tests. NeurIPS: name the variability factor (split, init, run).

## Discussion

What the findings mean. Relation to prior work. **Limitations** (honest; NeurIPS reviewers instructed not to penalize). Do not repeat Results. Do not smuggle new methods/results into Limitations (ACL).

NeurIPS checklist: **NA** = the paper has no limitation (almost never true). **No** = limitations exist but were not discussed — fail.

ACL ARR: Limitations section required after conclusion (desk reject if missing).

## References (Vancouver / ICMJE)

Numbered in order of first mention. Arabic numerals. MEDLINE abbreviations. One publication per number. **Every non-result number in the paper has a citation.** Open the DOI. No predatory journals. No AI-invented refs. “In preparation” stays in the text, not the list (Nature). Nature Articles: up to ~50 main-text refs; titles required; *et al.* after five authors. Science (search-confirmed): complete author lists, no *et al.*
