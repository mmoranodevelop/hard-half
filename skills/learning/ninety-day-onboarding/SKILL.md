# Ninety-Day Onboarding

**90-day person-in-role plan** — STARS diagnosis, learning agenda (questions with dates), 1–2 early wins matched to the situation, day-30/60/90 checkpoints, ASK for the boss conversation. Do not write a slogan 30-60-90. Default: incoming MD / program lead (venture unless they say F500).

Method origin: Watkins public STARS + learning-before-heroics; US OPM public executive onboarding phases. Reconstruct the fields. Do not quote the book.

If they want a lecture on the first 90 days: one paragraph then produce or stop.

## When to use

- "Build my first 90 days" / onboard this senior hire
- Incoming leader, internal promotion, or external hire at MD / program-lead altitude
- A 30-60-90 deck exists and is wallpaper
- Boss and hire do not share a definition of success

## When not to use

- Program mandate, scope, governance — [Program Charter](../../management/program-charter/SKILL.md)
- Stakeholder map / influence sequence — [Stakeholder Alignment](../../management/stakeholder-alignment/SKILL.md)
- One irreversible bet — [Decision Journal](../../learning/decision-journal/SKILL.md)
- After day 90 as a look-back — [After Action Review](../../management/after-action-review/SKILL.md)
- Teaching a method to the team — [Team Method Transfer](../../learning/team-method-transfer/SKILL.md)
- Opening the role / loop / debrief — [Hiring Scorecard](../../management/hiring-scorecard/SKILL.md)
- Who reports where — [Org One-Pager](../../management/org-one-pager/SKILL.md)
- Work matrix — [RACI Delivery](../../project/raci-delivery/SKILL.md)

## Modes

| Mode | When | Output |
|---|---|---|
| **produce** | Default (including a start date already passed) | Diagnosis + 90-day plan + ASK |
| **redline** | Pasted 30-60-90 | Same facts; STARS + real dates; slogans killed |
| **refuse** | No role/start, or they want a charter | Issues list. Stop |

Start date already passed: still produce, mark days spent. Day-30/60/90 check is still produce.

## Hard rules

1. **Name STARS first** (one primary): Start-up / Turnaround / Accelerated growth / Realignment / Sustaining success. Early wins must match it.
2. **Learning agenda before heroics.** Questions, from whom, by day. "Get up to speed" fails.
3. **Negotiate success with the boss** — or label the plan **draft**. Observable at 30/60/90.
4. **1–2 early wins**, visible, honest, kill criteria. Theatre wins fail.
5. **Horizons are dated actions, not slogans.** 0–30 learn/relationships (few irreversible moves unless turnaround). 31–60 refine + start wins. 61–90 direction they can say aloud.
6. **Stakeholder map is a pointer:** names to meet; run the other skill for power/sequence.
7. **Few A-item year-one priorities;** the 90 days serve one or two.
8. **Hire-side:** name what the org owes (access, context pack, predecessor briefing, buddy, day-30). Not a charter: no RAID dump.

## Intake

If **role/start** and **what success was said to be** are both missing after one ask: refuse.

1. Who (incoming person vs hire you own) + role + start date + internal/external — load-bearing
2. Boss and meeting cadence
3. What they were told success is — load-bearing
4. STARS guess + evidence
5. Team inherited (size, known issues)
6. Quiet periods / board dates
7. Stakeholder map already exists? (yes → pointer; no → names only)

## QA (must pass)

1. STARS named; early wins match it; dates on wins.
2. Learning agenda is questions with "by day" — not "get up to speed".
3. Success at 90 is observable or explicitly DRAFT.
4. Stakeholder map pointed at the other skill; names to meet are here.
5. Not a program charter (no scope/RAID/benefits dump).
6. Horizons are dated actions, not slogans. Day-30 is a calendar date.
7. ASK has owner + date.
8. One page plus the tables.

If 1, 2, 5, or 7 fail: do not ship.

## Escalate / stop

- They want a transformation charter → [Program Charter](../../management/program-charter/SKILL.md).
- They want a 2×2 map here → [Stakeholder Alignment](../../management/stakeholder-alignment/SKILL.md); keep the name list.
- Theatre "quick wins" → refuse; match STARS.
- Start date was almost the whole 90 already → do not fake a 90; write a short close + 91–180.
- Legal / works-council constraints → holes, not a playbook.
