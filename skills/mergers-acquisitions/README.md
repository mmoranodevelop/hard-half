# mergers-acquisitions

Post-close integration: product, people, stack, brand, and Day-1.

## Model-invoked

Reachable by you *or* selected automatically by the agent when a task matches.

- [`acquired-org-onboard`](acquired-org-onboard/SKILL.md) — Use to onboard the bought organisation as cohorts with Day-1 access, 30/60/90 moments, and a receiving-BU takeover date.
- [`brand-architecture-deal`](brand-architecture-deal/SKILL.md) — Use after a close to pick Day-1 signal and end-state architecture (endorsed / hidden / branded house).
- [`contract-novation`](contract-novation/SKILL.md) — Use when a deal needs a consent / novation log: stock vs asset, notice vs consent vs public-sector novation, close-critical vs post-close.
- [`control-handover`](control-handover/SKILL.md) — Use when handing control at close: GC / CISO / CFO sign the register (bank mandates, IdP, domain, repos, IP assignments, hold-separate denies).
- [`culture-fault-lines`](culture-fault-lines/SKILL.md) — Use in the first 30 days post-close to write a 6–8 row ways-of-working collision map (decisions, meetings, tools).
- [`day1-continuity`](day1-continuity/SKILL.md) — Use for close go/no-go: payroll, legal entity, bank, access for critical roles, customer comms.
- [`day1-employee-pack`](day1-employee-pack/SKILL.md) — Use for legal-cleared Day 1 employee words: what is changing, what is not, what is not yet decided.
- [`flight-risk-90`](flight-risk-90/SKILL.md) — Use for a 90-day post-close flight-risk watchlist with this-week conversation owners.
- [`imo-charter`](imo-charter/SKILL.md) — Use when standing up the Integration Management Office for a named deal: integration thesis, D, Integration Leader, Value Lead, Day 1 vs end-state.
- [`joint-roadmap-q1`](joint-roadmap-q1/SKILL.md) — Use after a close to publish a joint 2-quarter roadmap: what ships, what is frozen, what is not promised.
- [`key-talent-slate`](key-talent-slate/SKILL.md) — Use after a close (or in the sign-to-close window) to name retain / walk-away / watch for one deal, with stay-bonus yes/no.
- [`leadership-day1`](leadership-day1/SKILL.md) — Use to name who runs the combined unit on Day 1, including CEO–1: interim vs end-state, empty box = interim + date.
- [`named-account-day1`](named-account-day1/SKILL.md) — Use in the close week so every named account has one owner, a written script, and an SLA freeze.
- [`operating-model-choice`](operating-model-choice/SKILL.md) — Use when choosing hold / absorb / merge / harvest per function after a deal, plus Day-1 interim vs end-state.
- [`packaging-collision`](packaging-collision/SKILL.md) — Use after a close when two price lists meet: map every collision, freeze quotes, grandfather named accounts.
- [`portfolio-keep-kill`](portfolio-keep-kill/SKILL.md) — Use after a close to label every SKU Keep / Kill / Combine / Harvest with a customer sentence, last-sell, last-support, owner.
- [`stack-decision`](stack-decision/SKILL.md) — Use after a close to pick, per domain, keep-buyer / keep-target / dual-run / rewrite.
- [`synergy-tracker`](synergy-tracker/SKILL.md) — Use when a deal needs baseline-locked cost and revenue run-rate versus leakage, monthly finance recon.
- [`title-grade-map`](title-grade-map/SKILL.md) — Use to freeze titles and pay on Day 1, then date a role-to-family-to- grade map with red/green/hold.
- [`tsa-schedule`](tsa-schedule/SKILL.md) — Use when the seller is the bridge after a carve-out or close: TSA catalog, monthly cost and markup, exit test plus date per service.
